# public/admin/

管理者が配信者と使える機能を管理する画面です。

| ファイル | 何をするか |
| --- | --- |
| `admin.js` | 配信者の一覧、配信中の数字、表示名、案内文、遊び方・配信テンプレートの表示名を出す |
| `admin-errors.js` | エラーの一覧、状態、詳しい記録を出す |
| `admin-list.js` | 左の配信者の一覧。確認中のプランの申し込みがある人に「申し込み」の印を付ける |
| `admin-detail.js` | 右の配信者の詳しい画面。「プランの申し込み」で確認中のものを並べ、「確かめて有効にする」（プラン・支払い済み・支払った日まで +1か月を入れて履歴に残す）・「解約を確かめる」・「見送る」を1回押しで行う。入金の記録は持たない |

サーバー側の管理 API と、配信者用ダッシュボードを使います。
