# public/admin/

管理者が配信者と使える機能を管理する画面です。

| ファイル | 何をするか |
| --- | --- |
| `admin.js` | 配信者の一覧、配信中の数字、表示名、案内文、遊び方・配信テンプレートの表示名を出す |
| `admin-ledger.js` | 利用者ごとの未集金額、前回集金からの増分、月次売上推移を見て、集金・訂正・取り消しを記録する |
| `admin-billing.js` | 配信者のプランと紹介コードの発行・適用 |
| `admin-money.js` | 月額入金・紹介報酬を管理し、自動更新時も開いている訂正欄とスクロール位置を保つ |
| `admin.css` | 管理画面のカード配置と余白。月額入金の記録ボタンは画面幅に合わせ、ラベルを背景内に収める |

サーバー側の管理 API と、配信者用ダッシュボードを使います。
