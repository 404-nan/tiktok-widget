はじめに OBSに出す ルーレット 延長タイマー ためす 困ったとき

はじめに

  1. もらった短い URL を開き、4桁の数字を入れます。
  2. 左上に TikTok のユーザー名（@ のあと）を入れて「接続」。配信中ならギフトが届き始めます。
  3. 左の「出すものを選ぶ」で、使うもの（ギフト通知・ルーレット・延長タイマーなど）を選びます。出さなくしても設定は消えません。

OBS・TikTok LIVE Studio に出す

  1. 左の「OBSに入れるURL」を開き、出したいものの「コピー」を押します。
  2. OBS（または LIVE Studio）で「ソースを追加」→「ブラウザ」を選び、URL 欄に貼ります。
  3. 幅と高さは、URL の下に出ている数字に合わせます。
  4. 1つずつ別のソースにします。まとめて1つにしたいときは「1つにまとめる」の URL を使い、そこで場所と大きさをドラッグで決めます。

ルーレット

  • 「回すギフト」でギフトを選ぶと、そのギフトが届いたときだけ画面に出て回ります（ふだんは隠れています）。
  • 項目の数字は当たりやすさ。2 にすると 1 の2倍当たりやすくなります。
  • 項目の左の四角を押すと画像を選べます。右クリック（スマホは長押し）で差し替え・外すができます。
  • 「見た目」の「大きさ（倍）」で全体の大きさを変えられます。

延長タイマー

  • 「このギフトで決まった時間だけ延ばす」でギフトを選ぶと、100コイン＝1分の目安で長さが入ります。数字は自由に変えられます。
  • 「延ばす」「減らす」を選べます。単位は秒か分です。
  • 残りが少なくなると、画面に大きくカウントダウンが出ます。

配信前にためす

  • 各画面の「ためす」にある「見本のギフトを出してみる」で、実際の動きを確かめられます。
  • 配信中にためしても、ランキングや記録・Minecraft には入りません。
  • 「デモを流す」はギフトをまとめて流して、全体の動きを見るためのものです。

困ったとき

  • OBS に何も出ない：URL を貼り直し、ソースを右クリック →「プロパティ」→「現在のページのキャッシュを更新」を押します。ルーレットはギフトが来たときだけ出ます。
  • 接続できない：ユーザー名に @ を入れていないか、配信が始まっているかを確かめます。それでもだめなら管理者に連絡してください。
  • 設定を消してしまいそう：「使うのをやめる」は設定を残したまま隠すだけです。
