使い方

はじめての人は上から順に。困ったときは見出しから探してください。

はじめに

  1. もらった短い URL を開き、4桁の数字を入れます。
  2. 左上に TikTok のユーザー名（@ のあと）を入れて「接続」。配信中ならギフトが届き始めます。
  3. 左の「出すものを選ぶ」で、使うもの（ギフト通知・ルーレット・延長タイマーなど）を選びます。出さなくしても設定は消えません。

OBS・TikTok LIVE Studio に出す

  1. 左の「OBSに入れるURL」を開き、出したいものの「コピー」を押します。
  2. OBS（または LIVE Studio）で「ソースを追加」→「ブラウザ」を選び、URL 欄に貼ります。
  3. 幅と高さは、URL の下に出ている数字に合わせます。
  4. 1つずつ別のソースにします。まとめて1つにしたいときは「1つにまとめる」の URL を使い、そこで場所と大きさをドラッグで決めます。

OBSのカメラを動かす

  1. OBSの「ツール」→「WebSocketサーバー設定」でWebSocketを有効にし、パスワードを作ります。
  2. 透明なブラウザソースに、OBS連携のURLを入れ、末尾に #pw=パスワード を自分で足します。パスワードはサーバーへ送られません。
  3. ダッシュボードの「OBS連携を使う」を入れ、動かすカメラのソース名とルールを設定します。
  4. 配信前はダッシュボードの「ためす」から確認します。動かないときはOBSのポート（通常4455）とソース名を確かめます。

ルーレット

  • 「回すギフト」でギフトを選ぶと、そのギフトが届いたときだけ画面に出て回ります（ふだんは隠れています）。
  • 項目の数字は当たりやすさ。2 にすると 1 の2倍当たりやすくなります。
  • 項目の左の四角を押すと画像を選べます。右クリック（スマホは長押し）で差し替え・外すができます。
  • 「見た目」の「大きさ（倍）」で全体の大きさを変えられます。

延長タイマー

  • 「このギフトで決まった時間だけ延ばす」でギフトを選ぶと、100コイン＝1分の目安で長さが入ります。数字は自由に変えられます。
  • 「延ばす」「減らす」を選べます。単位は秒か分です。
  • 残りが少なくなると、画面に大きくカウントダウンが出ます。

配信前にためす

  • 各画面の「ためす」にある「見本のギフトを出してみる」で、実際の動きを確かめられます。
  • 配信中にためしても、ランキングや記録・Minecraft には入りません。
  • 「デモを流す」はギフトをまとめて流して、全体の動きを見るためのものです。

外部ツールからイベントを受ける

ダッシュボードの「接続の状態」で受け口の鍵を作り、表示された URL を外部ツールの送信先に貼ります。URL は https://このサーバー/in/<ここに鍵> の形です。鍵の全文は作成時に1回だけ表示されます。鍵を URL に入れるため、Cloudflare やプロキシのアクセスログに鍵が残ることがあります。漏れたらダッシュボードで鍵を作り直してください。

TikFinity

TikFinity の公式の Streamer.bot 連携で使える項目名に合わせます。Webhook の送信方法は、使っている編集画面に表示される項目名で合わせてください。

受け口が読める項目: userId username nickname avatar avatarUrl avatar_url profilePictureUrl giftId giftName coins repeatCount likeCount totalLikeCount comment content text commandParams

  • ギフト: https://このサーバー/in/<ここに鍵>?kind=gift&userId=%userId%&username=%username%&nickname=%nickname%&giftId=%giftId%&giftName=%giftName%&coins=%coins%&repeatCount=%repeatCount%
  • いいね: https://このサーバー/in/<ここに鍵>?kind=like&userId=%userId%&username=%username%&nickname=%nickname%&likeCount=%likeCount%&totalLikeCount=%totalLikeCount%
  • フォロー: https://このサーバー/in/<ここに鍵>?kind=follow&userId=%userId%&username=%username%&nickname=%nickname%
  • コメント: https://このサーバー/in/<ここに鍵>?kind=comment&userId=%userId%&username=%username%&nickname=%nickname%&comment=%commandParams%
  • シェア: https://このサーバー/in/<ここに鍵>?kind=share&userId=%userId%&username=%username%&nickname=%nickname%

Streamer.bot

公式の Fetch URL の送信方法をこの画面で確認できていないため、設定手順は準備中です。受け口の URL と項目名は、公式説明書と編集画面で確認して合わせてください。

送れないとき

同じイベントの再送は二重に数えません。送信は1秒20回まで（瞬間40回まで）です。不正な鍵も送信元ごとに照合の上限を設けています。404 は鍵違い、403 は止められた配信者、429 は送りすぎなので、鍵と送信間隔を確認してください。

外部ツールだけで配信していて TikTok に直接つないでいないときは、テスト送信も集計に入ります。配信前に試すか、配信中は TikTok に直接つないでから試してください。

困ったとき

  • OBS に何も出ない：URL を貼り直し、ソースを右クリック →「プロパティ」→「現在のページのキャッシュを更新」を押します。ルーレットはギフトが来たときだけ出ます。
  • 接続できない：ユーザー名に @ を入れていないか、配信が始まっているかを確かめます。それでもだめなら管理者に連絡してください。
  • 設定を消してしまいそう：「使うのをやめる」は設定を残したまま隠すだけです。

もっとくわしく知りたいとき

  • はじめて使う：URL を1本入れて、つないで、テストするまで
  • 配信テンプレート：配信の種類を選んで、設定をそろえる
  • ウィジェットの紹介：何が起きるか、どんな配信に向くか
  • スマホで変える：配信中に手元で押すもの
  • つなぎ方：TikFinity など、ほかの道具から送る方法と OBS 連携
  • よくある質問：うまくいかないときの直し方
