# public/dashboard/

配信者が配信の準備、設定、外部ツールの接続、テスト送信、ウィジェット、AI接続を行う画面です。hosted の配信者 URL では、期限が近い案内だけをホーム内に表示し、スマホではメニューを閉じて本文を全幅で表示します。公開画面の JavaScript は ES5 ですが、管理画面はこの制約の対象外です。

## 画面の部品

- ページの形: 見出し、1行の説明、中身
- カード: 同じ幅、同じ余白、線で区切った行
- ボタン: 主役、ふつう、目立たないの3種類
- モーダル: 見出し、本文、「やめる」と実行ボタン
- 状態の印: 丸の色と、人の言葉
- 下に出るお知らせ: 保存や削除の結果と、必要なら元に戻す

画面の言葉は [../../docs/words.md](../../docs/words.md) に合わせます。外部ツールの鍵や細かい接続状態は「設定」内の「くわしい人向け」に閉じています。

## 使われ方

`index.html` が `app.js` を読み、`app.js` が各画面部品を読みます。`src/schema.js` の設定定義を `simple.js` と対応させ、保存は `/api/config`、配信テンプレートは `/api/templates`、受け口の状態は `/api/ingest` と `/api/status` を使います。`/t/<ダッシュボード鍵>/dashboard/` から `/api/ai/streamer` を使い、OBS鍵ではこの入口を開けません。段階写真は `media/` の候補を選びます。

画面の明るさは設定画面のボタンでライトとダークを切り替えます。プリセットの名前は名前の部分をダブルクリックするか、プルダウンの名前を変えるから変更できます。

## 並び方と色(2026-10-25 作り直し)

- PC(幅 900px から): 左に細いアイコンの列(`#side`、84px)、上の帯(`#rkTop`。名前・状態・つなぐ欄・ためしに動かす・配信中に見る・配信の記録)。どちらも `editor.js` の `renderNav()` が作る
- スマホ: 下のタブ(`#rkTabs`)。ウィジェットは横から出る一覧、その他は設定・使い方・その他のウィジェットの画面
- 配信中に見る・配信の記録は、`/monitor/?embed=1`・`/history/?embed=1` を枠の中に開く(`embed=1` のときはその画面の上の帯を出さない。`common.js` の `setupChrome`)
- 見え方の枠は「このウィジェットだけ / 配信画面ぜんぶ」(`all.html?preview=1`)を切り替える
- 色は `style.css` の先頭の「色の置き場」と、末尾の「ライコネの色」(ダーク=炭色に黄 #FFE600、ライト=紙 #F3F1EC に朱)だけで決める。部品の中に色を直に書かない(`test/acceptance/redesign.test.js` が確かめる)
- 見本のデザインは `docs/design/redesign/`
