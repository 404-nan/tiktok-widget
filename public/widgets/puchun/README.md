# パチンコ演出(見本)

ライコネのギフト演出の見本。パチンコの演出を、部品を「何秒目に何を出すか」で並べたタイムラインだけで組み立てる。いちばん大きい「プチュン」は参考動画 `ref/reference.mp4`(6.8秒、パチンコの「プチュン」から大当たり)を組み直したもの。ほかの演出は同じ部品の組み替え。配信画面に重ねるウィジェットで、背景は透明。縦 1080x1920 でも横 1920x1080 でも崩れないように描く。音はなし。

この演出だけは、パチンコの派手さ(金属の金・虹・光のにじみ)がねらいなので、ふだんの「つや・グラデーションを使わない」決まりは当てはめない。

状態: 見本(作りかけ)。ライコネの `public/widgets/puchun/` に置き、開発サーバーの `/widgets/puchun/try.html` で開ける。本番にはまだ入れていない。立ち絵(`assets/`)は入れていない(`?char=` が無いと仮の影)。

## ギフトで流す設定

`puchuns` に条件ごとの設定を作る。`gifts` のギフト名または GiftID を指定すると、コイン数より先に選ばれる。`minCoins` と `maxCoins` は合計コインの範囲で、`maxCoins: 0` は上限なし。初めは設定がなく「使わない」状態。

`preset` は `chance` / `cutin` / `jackpot` / `puchun`、比率は `full` / `1:1` / `4:3` / `16:9`。`texts` には演出のキー(`main` など)と、そのまま表示する字を書く。連打は個数ぶんすべて順に流し、上限や飛ばしはない。

最後に直した日: 2026-10-30(ライコネに置いた日)

## 動かし方

```
node serve.cjs &                 # サーバー
# ブラウザで http://127.0.0.1:3961/puchun.html
# 演出をためす画面 http://127.0.0.1:3961/try.html
node sheet.cjs                   # 演出ごとの要の場面 → shots/sheet-{名前}.png
node sheet.cjs --q="main=とても長い字"   # 字を変えて撮る → shots/sheet-{名前}-long.png
node compare.cjs                 # 比べる1枚 → shots/compare.png
node compare.cjs 1.4 3.9         # 時刻を選んで比べる
node shoot.cjs 30                # 動画にする(横と縦)
node shoot.cjs 30 1280x720       # スマホで見る用 → shots/puchun.mp4(効果こみ)
node perf.cjs 1080x1920          # 1コマの時間を測る
```

ページの値: `?preset=chance|cutin|jackpot|puchun`(演出。無いときは puchun)、`?main=字` など(画面の字。キーは下の「演出の一覧」。カンマで行を分ける。20字まで)、`?char=画像URL`(配信者の立ち絵。透過PNG)、`?text=`(`main` と同じ。前の書き方)、`?t=3.8`(その時刻で止める)、`?loop=1`(くり返し)、`?reduced=1`(動きを減らす版)、`?post=0`(仕上げなし)、`?ratio=1:1`・`4:3`(演出の縦横の比。まん中に置く。無いときは画面いっぱい)。

## 演出の一覧

ギフトの大きさに合わせて強さを分けた。パチンコの予告の色の段階(青 < 赤 < 金 < 虹)に合わせ、大きいほど字の色が上がる。

| `?preset=` | 名前 | 合うギフト | 長さ | 中身 | 画面の字(`?キー=`) |
| --- | --- | --- | --- | --- | --- |
| `chance` | チャンス予告 | 小 | 1.6秒 | 画面を暗くしない。赤い帯が走り、赤と金の字が出る | `main` 大きい字(チャンス!)、`sub` 帯の字 |
| `cutin` | キャラのカットイン | 中 | 2.9秒 | 白い斬撃 → 青い斜めの帯で立ち絵が飛びこみ、セリフ → 爆発の光に赤と金の字 | `say` セリフ(長いと2行)、`main` 決めの字 |
| `jackpot` | 大当たり | 大 | 5.4秒 | 暗転 → 斬撃 → 図柄が回って、リーチで赤く脈打つ → そろってガラスが割れ、虹の字と立ち絵で決め | `num` そろう図柄(5字まで)、`main` 決めの字、`sub` 帯の字 |
| `puchun` | プチュン | 特大 | 6.8秒 | 参考動画の組み直し(下のタイムライン) | `main` 決めの字(ナイス,ギフト) |

演出を足すときは `presets.js` に1つ書く(`label`・`size`・`about`・`fields`・`timeline(T)`)。`T.キー` に画面の字が入る。`try.html` は `presets.js` から一覧と字の欄を作るので、書き足すだけで出る。

## タイムラインの書き方

```js
{ t: 1.33, part: 'slash', dur: 0.2 },
{ t: 1.4,  part: 'post',  dur: 0.13, ca: 3, decay: true },
```

- `t` 何秒目から(`at` でもよい)、`dur` 何秒間、`part` 部品の名前。ほかは部品ごとの値
- あとの行ほど上に重なる。同じ時刻なら毎回同じ絵(乱数は `seed` で決まる)
- 部品を並べ替えれば別の演出になる。部品を足すときは `parts.js` に `P.名前 = function (ctx, t, p, env) {}` を書く(`t` は部品の中の進み 0〜1、`env.W/H` は画面の大きさ、`env.S` は短い辺/1080)
- `shake` と `post` は絵を描かない。その間、画面のゆれと仕上げの強さを足す
- 字の立体など重い下ごしらえは、流す前に `fx.warm()` で1回だけ作る(途中で止まらないように)

## 仕上げ(`part: 'post'`)の値

ふだんから少しかかっていて(光のにじみ・色ずれ・粒・周りを暗く)、`post` の行がその間だけ足す。

| 値 | 何をするか |
| --- | --- |
| `bloom` | 明るいところの光のにじみ。`thr` で光り始める明るさ |
| `ca` | 色ずれ(赤と青を外へずらす) |
| `blur`, `angle` | ぶれの長さ(px)と向き(度) |
| `zoom` | まん中から外へのぶれ(叩きつけ・飛びこみ) |
| `swirl` | うず(まん中ほど強くねじる。ラジアン) |
| `scan` | 走査線 |
| `flash` | 白飛び(0〜1) |
| `grain`, `vig` | 粒、周りを暗く |
| `decay: true` | はじめが強く、だんだん弱まる |

WebGL2 が使えないとき、または流して 25fps を切るときは、仕上げを外して 2D の絵をそのまま出す。

## 重さ(2026-10-29 に lulserver で測った)

lulserver の headless chromium は GPU が使えず、Canvas も WebGL もすべて CPU(SwiftShader)で描くので、配信ソフトより大幅に遅い数字になる。

| 1080x1920 | 2D だけ | 仕上げこみ(CPU の WebGL) |
| --- | --- | --- |
| そのまま | 平均 70ms / 95% 153ms | 平均 1035ms |
| `?scale=0.5` | 平均 27ms / 95% 63ms | 平均 305ms |

ほかの演出(2026-10-30、1080x1920、2D だけ): chance 平均 27ms / 95% 78ms、cutin 平均 52ms / 95% 90ms、jackpot 平均 40ms / 95% 93ms。重いのは字の叩きつけの瞬間。`node perf.cjs 1080x1920 1 jackpot` で測る。

GPU のあるパソコン(OBS・TikTok LIVE Studio)ではまだ測っていない。本番に入れる前に、配信に使うパソコンで `perf.cjs` と同じ測り方をする。
