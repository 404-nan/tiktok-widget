# 演出の音（自作の合成音）
外部の音源は使わず、数式だけで合成した WAV（44.1kHz / 16bit / モノラル）。
- charge.wav（0.95秒）: 溜め。上昇する電子音＋小さな鼓動
- flash.wav（0.40秒）: 閃光。鋭い金属音＋低音の腹打ち
- slam.wav（0.75秒）: 決め字の叩きつけ。太鼓の胴打ち＋紙を打つ音
- sparkle.wav（2.10秒）: 余韻。鈴のアルペジオ
- out.wav（0.45秒）: 終わり。すっと引く音
- whoosh.wav（0.32秒）: 斬撃・カットインの風切り
鳴らす拍は presets.js の各プリセットの sound に書く。再生は sound.js。
