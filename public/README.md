# public/

配信者向けのダッシュボード、ヘルプ、モニター、履歴、公開ウィジェットを置きます。

| フォルダ | 役目 |
| --- | --- |
| `dashboard/` | 配信者の設定・テスト送信・AI接続画面 |
| `help/` | 配信者向けの日本語手順 |
| `widgets/` | OBS / TikTok LIVE Studioに表示する公開ウィジェット |
| `monitor/` | 配信中の状態を見る画面 |
| `history/` | 配信履歴を見る画面 |

`server.js` がURLごとの権限を確認して静的ファイルとAPIを配ります。公開ウィジェットのJSはES5で、外部CDNを使いません。
