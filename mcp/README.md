# mcp/

AIクライアント向けのMCPサーバーです。

| ファイル | 役目 |
| --- | --- |
| `server.js` | OBSを含む管理ツールをMCPとして公開 |

操作の実体は`src/admin.js`にあります。
設定や配信テンプレートを操作する MCP サーバーです。

| ファイル | 何をするか |
| --- | --- |
| `server.js` | ローカル／リモートの MCP 道具を登録し、テンプレート操作をサーバー API に渡す |

CLI と同じ開発サーバーのテンプレート API を使います。
AIがTikTok LIVEウィジェットを読み取り・設定・テストするためのMCP入口です。

| ファイル | 何をするか |
| --- | --- |
| `server.js` | stdio MCPを起動し、開発サーバー接続時は撮影道具を含むAI操作を登録する |

## つながり

- 使うもの: `../src/ai-mcp.js`、`../src/ai-screenshot.js`、`../src/admin.js`
- 使われるところ: Claude CodeなどのMCPクライアントから起動される
