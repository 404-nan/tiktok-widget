# 画面の言葉

ダッシュボードで使う言葉をそろえる表です。コードの設定キーや API の名前は変えません。

| 使う言葉 | 使わない言葉 | なぜ |
| --- | --- | --- |
| ウィジェット・その他のウィジェット | 配信に出すもの・出すものを増やす | 配信者がふだん使う呼び方に合わせる(2026-10-25 オーナーが決めた) |
| 配信の記録 | これまでの配信 | 何が見られる画面かが分かる |
| 配信ソフトに入れる URL | OBS / TikTok LIVE Studio に入れる URL | 配信ソフトをまとめて呼ぶ |
| 目立ちかた | 出しかた | 見え方が伝わる |
| シンプル・ふつう・ドパガキ | ひかえめ・はでに・しっかり | オーナーが決めた呼び方。1本につながったボタンで選ぶ |
| プリセット | 種類 | 保存した設定を指す |
| くわしい人向け | API・MCP・テナント・トークン | 開発の仕組みを通常画面に出さない |
| 外部ツール | 受け口 | 配信者が知っている呼び方にする |
| 条件 | ルール | 何が起きたときかを明確にする |
| 設定ファイル | YAML・JSON | 形式名を通常画面に出さない |
| 接続の状態 | 接続 | 今どうなっているかを表す |
| マス(ルーレット)・中身 | 項目 | オーナーが「項目」という言い方をきらった(2026-10-25) |
| 配信ではこれが出る | 配信で使用中 | 配信につないでいなくても付くので、つないでいると読ませない |
| Plus で使えます・Pro で使えます | 利用不可・権限がありません・アップグレードが必要です | 使えない理由と、どうすれば使えるかを一言で伝える。鍵の印と一緒に出す |
| いまのプラン・仮の値段 | 契約・ライセンス・暫定価格 | 配信者がふだん使う言葉にする。値段が決まっていないことは隠さない |
| あと○日 | 残存日数・有効期限 | 期限が近いことが一目で分かる |
| 止めています | 停止処理中・サスペンド | 何が起きているかだけを言う。配信画面にはこの文を出さない |
