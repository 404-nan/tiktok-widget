# 画面の言葉

ダッシュボードで使う言葉をそろえる表です。コードの設定キーや API の名前は変えません。

| 使う言葉 | 使わない言葉 | なぜ |
| --- | --- | --- |
| 配信に出すもの | ウィジェット一覧 | 配信者がしたいことを先に書く |
| 配信ソフトに入れる URL | OBS / TikTok LIVE Studio に入れる URL | 配信ソフトをまとめて呼ぶ |
| 目立ちかた | 出しかた | 見え方が伝わる |
| はでに | しっかり | 画面の印象を表す |
| 出す場所 | 左 | 位置を1つの選び方にする |
| プリセット | 種類 | 保存した設定を指す |
| くわしい人向け | API・MCP・テナント・トークン | 開発の仕組みを通常画面に出さない |
| 外部ツール | 受け口 | 配信者が知っている呼び方にする |
| 条件 | ルール | 何が起きたときかを明確にする |
| 設定ファイル | YAML・JSON | 形式名を通常画面に出さない |
| 接続の状態 | 接続 | 今どうなっているかを表す |
