# 妨害マイクラ

## WIN数と演出

- WIN数はゲームのクリア回数。クリア操作で `+1`、ギフトのルールで増減・指定値設定・0へのリセットができ、通常は配信をまたいで保存する。
- 設定は `wins.<名前>`。`negative: false` なら0未満にしない。過去の変更は最大50件をundoできる。
- 減少の段階は通常 → 大妨害 → 超妨害 → 壊滅。増加も通常 → 大 → 超 → 最大。量の境目は `lossPreset` / `gainPreset` または個別値で変える。
- 15秒以内の連続した減少は連続妨害として数え、×3、×5、×8で演出段階を上げる。目標達成や最低記録更新などは別の演出イベントになる。

## SuperStream とRCON

- `src/minecraft.js` がイベントをルールに照合し、MinecraftのRCONへコマンドを順番に送る。
- `forwardGifts` ではギフトIDに対応するSuperStream演出を渡せる。`superstreamProfile` とプロフィールファイルはMinecraft設定で指定する。
- ルーレットの当たり、ボス討伐にも `commands`、`superstreamGift`、`superstreamAction` を設定できる。
- キュー上限、ギフト個数上限、送信間隔がある。接続失敗時は状態とログを画面へ出し、無制限に詰め込まない。

## 配信の技術的な決まり

- 配信中にMinecraftを再起動しない。`/reload`、datapackの再読み込み、設定の直接変更もしない。
- TNT・爆発・ブロック破壊・プレイヤーへのダメージを伴う演出は禁止。安全な演出コマンドだけを使う。
- RCONのホスト、ポート、パスワードはAI変更対象外。ログ、画面、コミットに出さない。
- 動作確認は開発環境で `minecraft_command` またはCLIの `mc` を使う。実サーバーへ送る前に対象とコマンドを確認する。

## プラグイン・MOD の入れ方

- 公式の配布所(Hangar、Modrinth、SpigotMC、作者の公式サイト)からだけ入れる。GitHub Releases の jar、フォーク、再配布サイトからは入れない(2023年の fractureiser では、改ざんされた MOD・プラグインでログイン情報が盗まれた)。
- 入れる前にオーナーに聞く。配信中には入れ替えない。
