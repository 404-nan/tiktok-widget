# 演出とウィジェットのアイデア集

「ギフトを送った人の脳汁がドパドパ出る」演出と、配信を回しやすくする普通のウィジェットの案。
実装済みのものには ✅、次に作るとよいものには ★ を付けています。

---

## 1. 脳汁が出る仕組み（パチンコから学ぶこと）

パチンコの演出は、何十年もかけて「気持ちよさ」を磨いたものです。形をまねる前に、効いている理由を押さえておきます。

| 原則 | パチンコでは | 配信に置き換えると |
| --- | --- | --- |
| **溜めてから放つ** | リーチ → 静止 → 大当たり。待たされた分だけ解放が大きい | 結果をすぐ出さない。0.5〜1秒の「溜め」を必ず入れる（カットインの入り、ルーレットの減速、スロットのリーチ） |
| **色で期待度を覚えさせる** | 青 < 緑 < 赤 < 金 < 虹（キリン柄・ゼブラ柄） | 金額やレア度を色の段階に固定する。視聴者が「赤が出た！」と一目で分かる共通言語になる |
| **予兆（先読み）** | 保留の色が変わる、何かが起きそうな気配 | 結果の前に小さな「前ぶれ」を出す。待っている時間も楽しくなる |
| **段階的に上がる** | ステップアップ予告、擬似連 ×2 ×3 … | 連続ギフトや短時間の合計で、演出が一段ずつ派手になる |
| **ごくまれな裏切り** | プレミア演出、フリーズ | 数百回に1回の特別な演出。「見たことない！」が一番の脳汁 |
| **音の落差** | 無音 → キュイン | 一瞬静かにしてから爆音。音量より「落差」が効く |
| **主役は当てた人** | 自分の台が光る | 送った人の名前とアイコンを大きく出す。「自分のギフトで画面が変わった」体験が次のギフトを生む |
| **短く、繰り返しても飽きない** | 2〜3秒、毎回少しずつ違う | 1回 3秒以内。筆跡・角度・言葉を毎回ランダムに変える |
| **安売りしない** | 激アツが毎回出たら価値がない | 赤以上はまれにする。金額のしきい値は配信の規模に合わせる（下の「自動調整」） |

## 2. 脳汁系の演出

### ✅ カットイン（`/widgets/cutin.html`）と画像付きカットイン（`/widgets/image-cutin.html`）
筆でかすれた帯がフィーンと入り、「激アツ」の文字が叩きつけられ、ガガガガと揺れてスッと抜ける。
- コインで 青（チャンス）→ 緑 → 赤（激アツ）→ 金（超激アツ）→ 虹（確定）
- 虹は画面が暗転して止まり（フリーズ）、「キュイン」で明ける
- 帯の筆跡は毎回ランダムに生成。集中線、効果音（フィーン・ドン・ガガガ・スッ・キュイン）も合成
- **通常カットイン**（`cutins`）: 帯と文字だけ
- **画像付きカットイン**（`imageCutins`）: 写真を使う。inside は帯の中いっぱいに写真が入り、上下の縁が木炭でガシガシかすれた線になる。side は色の帯の横に写真が大きく乗る（背景を切り抜いた PNG がおすすめ）
- 両方を OBS に入れるときは、通常カットインの `yieldToImage` で「画像付きが出るギフトのときは通常を出さない」にできる

**このあと足すとよいもの**
- **プレミア柄**（★）: どの段階でも 1/100 くらいの確率で、帯がキリン柄・ゼブラ柄・金の流体になる。確率だけで脳汁が出る
- **ボイス**: 段階ごとに「激アツ！」「確定ー！」の声。配信者が自分で録った声を `media/` に置けるようにする
- **色の昇格**: 青で入って、揺れている途中で「ピキーン」と赤に変わる（昇格演出）。同じ金額でもたまに昇格させると、毎回ドキッとする
- **段階ごとの写真**: 赤はこの写真、虹はこの写真、のように段階で写真を変える

### ★ 擬似連（コンボ）
同じ人が 10 秒以内に続けてギフトすると、「×2」「×3」「×4」…とドンッと数字が出て、そのたびに帯の色が1段上がる。途切れたら「×7 COMBO 合計 12,345 コイン」でしめる。
- トリガー: 同じユーザーの連続ギフト（連打のまとめとは別に、違うギフトでも数える）
- ねらい: 「もう1回送ったら赤になる」が見えるので、次のギフトが出やすい
- 実装メモ: サーバーでユーザーごとのコンボを数え、`combo` イベントを配る。表示はカットインの部品を使い回せる

### ★ スロット（リーチ演出つきルーレット）
ルーレットの3つ目の形。3つのリールが順に止まり、2つそろうと「リーチ！」で画面が点滅、3つ目がゆっくり回る。そろえば大当たり（777）、外れても「惜しい」が気持ちいい。
- 当たりの決め方はサーバー（今のルーレットと同じ）。リーチになるかどうかも演出として抽選する
- 項目ごとに絵柄（画像）を付けられる。当たった項目の `commands` / マイクラの演出も今と同じように送れる

### ✅ ステップアップ予告
短い時間（例: 30 秒）のギフトの合計で STEP 1 → 5 が1段ずつ出る。STEP 5 まで行くと虹のカットイン。
- 個人ではなく「みんなで」上げるので、少額の人も参加しやすい
- 画面の端に STEP の段が積み上がる小さな表示と、段が上がった瞬間の全画面の演出
- サーバーがテナントごとの合計と段階を持ち、ギフト1件につき一段だけ進めて WebSocket で配る。
- `stepup` の設定で時間、境目、最小コイン、冷却時間、音量、積み上がる側を変えられる。
- 配信中のテストと見本は状態を変えず、画面確認用の予告だけを配る。

### 保留変化（ルーレットの先読み）
ルーレットの待ち（保留）を色付きの玉で並べ、当たりのレア度に応じて玉の色が変わる（青 → 赤 → 金）。変わる瞬間に「ピキーン」。
- 回る前から「次は金だ…」とざわつく
- 結果はサーバーが先に決めているので、それを元に色を決められる（ガセの色変化も混ぜる）

### 群予告
5 秒以内にギフトが一定数を超えると、ギフトのアイコンが大群で画面を横切る。「群」の一文字がドンと出る。
- ギフトが集中した瞬間を「お祭り」にする。少額ギフトでも数で参加できる

### 役物落下
目標達成やフォロワーの節目で、画面の上から大きなロゴの板が「ガシャーン」と落ちてきて揺れる。パチンコ台の可動役物の再現。
- 目標バー・ボス討伐などの「達成」に使う

### PUSH ボタン（視聴者参加型）
画面に「押せ！」のボタンが出て、5 秒以内にコメントで「押」と打つか、いいねを連打すると押される → 結果が出る。
- パチンコの「PUSH ボタン」を視聴者にやってもらう。全員が当事者になれる
- コメント数やいいねの数で、押したときの演出の段階を変える

### ✅ RUSH（確変）モード（`/widgets/rush.html`）
突入すると全画面に虹の放射と「RUSH突入」が叩きつけられ、左右に「RUSH中」が縦に流れる帯が出る。帯の内側には虹色の筆のかすれ線（画像付きカットインの縁と同じ筆を、3枚の筆跡で切り替えてガシガシ動かす）と、波打つ光の線を伝って落ちる光の粒（シャワー）。
- 上に「RUSH 合計 ○○ コイン · 残り 0:42」と残り時間のゲージ。ギフトが来ると「+コイン」が出て光が一瞬強くなり、延びたら「時間延長 +5秒」でゲージが戻る
- 残り10秒で時計が赤くなり、1秒ごとにカチッと鳴る
- 最後に「RUSH 終了 合計 ○○ コイン / ギフト ○個 / 時間」
- 突入: 指定のギフト、一定以上のコイン、ルーレットの `rush: true` の項目、ボタン。RUSH 中にもう一度突入すると「RUSH延長」
- 「今送ると派手になる」時間を作る。盛り上がりが盛り上がりを呼ぶ

**このあと足すとよいもの**
- RUSH 中はカットインやギフト通知を1段派手にする（青 → 緑のように段階を上げる）
- RUSH 中だけ回るルーレットや、RUSH 中の上位ギフターを結果に出す

### しきい値の自動調整
配信の記録（統計）からギフトの金額の分布を出して、赤 = 上位 10%、金 = 上位 2%、虹 = 上位 0.3% のように自動で決める。
- 配信の規模が変わっても「激アツ」がちょうどよい珍しさに保たれる

### OBS 連携
OBS の WebSocket につないで、虹や大当たりのときにカメラのソースを揺らす・ズームする・シーンを切り替える。
- オーバーレイだけでなく、配信者の映像そのものが揺れると迫力が段違い

## 3. 普通のウィジェット

| 案 | 内容 | ひとこと |
| --- | --- | --- |
| ★ **ボス討伐 HP バー** | ギフトのコインがダメージになり、ボス（画像を差し替え可）の HP を削る。倒すと虹のカットインと Minecraft の演出 | TikTok でよく見る定番。みんなで一つの目標に向かえる |
| ★ **ガチャ** | ギフトでカプセルが出て、N / R / SR / SSR / UR のレア度で演出が変わる。出たものは「図鑑」にたまる | レア度＝脳汁。図鑑で毎回の配信に来る理由ができる |
| ★ **コメント欄** | テロップ風・吹き出し風のコメント表示。ギフトした人のコメントは色付き | 配信画面の基本。読み上げ（TTS）も付けられる |
| **延長タイマー** | ギフトで配信時間が延びるタイマー（サブアソン） | 長時間配信の定番 |
| **チーム対抗（綱引き）** | 「Rose 派 vs TikTok 派」のように、ギフトの種類でチーム分けしてバーを引き合う | 視聴者同士で競ってくれる |
| **投票** | コメントで「1」「2」「3」と打つと集計される | 次にやることを視聴者に決めてもらう |
| **初見さん・常連の入室** | 配信の記録から、初めての人と常連を見分けて歓迎する | 常連さんは名前で迎えられるとうれしい |
| **最近のサポーター** | 最新のフォロー・ギフトを小さなカードで並べる | 画面の端に置ける控えめな表示 |
| **ニュースティッカー** | 画面の下を流れる帯に、最近のギフトや目標の進み具合 | テレビの文法と相性がよい |
| **目標の階段** | 100 → 300 → 1000 のように段階のある目標。段ごとにご褒美を表示 | 次のご褒美が見えると頑張れる |
| **応援ゲージ** | いいねの連打でたまり、満タンでカットイン | お金を使わずに参加できる |
| **ビンゴ** | ギフトの種類ごとにマスが埋まり、そろうと演出 | いろいろなギフトを送ってもらえる |
| **コイン落とし** | ギフトが押し出しゲームのコインになって落ちる（物理演算） | ギフト瓶の仕組みを使い回せる |
| ✅ **WIN数** | 妨害マイクラなどのクリア回数。ボタン・Stream Deck で +1、ギフトで増減（`/widgets/wins.html`） | 配信をまたいで数が残る |
| **Now Playing・時計** | 流している曲名や時刻 | 地味だが毎回使う |

## 4. 次に作る順番のおすすめ

1. **擬似連（コンボ）** — カットインの部品を使い回せて、ギフトが続きやすくなる効果がいちばん大きい
2. **スロット（リーチ）** — ルーレットの仕組みにそのまま乗る。リーチの溜めは脳汁の王道
3. **ボス討伐 HP バー** — 視聴者みんなで盛り上がれる定番。Minecraft 連携とも相性がよい
4. **プレミア柄・昇格演出** — カットインに足すだけで、同じ演出が「毎回ちがう」ものになる
5. **ガチャ** — レア度と図鑑で、配信をまたいだ楽しみができる

どれも今の仕組み（`config.yaml` の設定、サーバーでの抽選、配信の記録、Minecraft 連携、AI からの設定）の上に作れます。
