# レビュー: puchun-gift 

レビュー結果です。`npm test` は 790 件中 788 件が通り、失敗 0、スキップ 2 でした。
1. 【直す】証拠の画面がカードを満たしていません。
   - `artifacts/shots/puchun-pc.png` は 1280×800 の真っ白な画像です。
   - `puchun-mobile.png` に映っているのは演出(`puchun.html`)だけです。
   - カードが求める「ダッシュボードの puchuns の項目と見本が流れた画面」が、スマホ幅にもパソコン幅にもありません。
   - 作業メモの `debug.png` も `artifacts/shots/` に入っています。
2. 【直す】演出を切り替えると、保存が断られる場合があります。
   - `public/dashboard/editor.js` は、演出(preset)を選ぶと preset だけを保存し、保存済みの `texts` は消しません。
   - `src/config.js` の `checkPuchunTexts` は、新しい演出に無いキーがあるとエラーにします。
   - 例えば chance で `sub` を保存したあと puchun に切り替えると、`sub` が残っているため保存が断られると読めます。
   - 実際には動かしておらず、コードを読んだだけの判断です。
   - テストは `texts` を直接保存するものだけで、preset を切り替える手順は見ていません。
3. 【軽い】`src/puchun.js` の `puchunTestPlay` と、`entry.id` を含む部分は、本番の入口から呼ばれていません。
   - `puchunTestPlay` はテストからしか呼ばれません。見本ボタンは、カードの3巡目の決めどおり URL を直接組み立てる形です。
   - 動かしても何も変わらない部品です。
4. 【軽い】`public/dashboard/editor.js` に、使われない `field.type === 'object'` の JSON textarea が増えています。
   - `texts` は専用の入力欄が先に処理するので、ここは通りません。
   - カードにない追加です。
5. 【軽い】`README.md` の機能の一覧に、カードが指定した「1行」ではなく 2 行(「パチンコ演出」と「パチンコ演出の本体」)足されています。
6. 【軽い】`public/widgets/puchun/puchun.html` は、演出ごとの長さを固定値(2200・3800・6500・8000 ms)で数え、次の iframe を出しています。
   - 実際の再生時間とずれた場合、次の演出と重なるか、間が空きます。
7. 【軽い】見本ボタンは入力欄の値をそのまま使い、`ratio` を渡しますが、ダッシュボードの見本枠は常に縦長の 1080×1920 です。
   - 比率を変えた見本が、実際の見え方と違って見える可能性があります。
カードにない変更は上の 4・5 と、`docs/reviews/` のレビュー記録です。`src/card-draw.js` の変更は戻っています。
既存機能を壊している箇所は見つかりませんでした。
AC-7 から AC-10 と、連打の個数分の指示はテストされています。ただしテストはどれも部品を直接呼ぶ形です。実際の `puchun.html` の iframe を動かして確かめたものではありません。前からあるテストを弱めた形跡はありませんでした。
