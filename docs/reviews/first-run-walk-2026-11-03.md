## 問題の一覧

### 止まる

今回の実画面では無い。説明を読めば①〜③まで進められた。

### 迷う

1. ②の URL 一覧に29行が出て、選んだウィジェットの行を探す必要がある（写真 `/tmp/first-run-walk/390-02-url.png`、`public/dashboard/editor.js:860-884`）。一覧の行数はこの確認時の画面で数えた値。
2. 「このウィジェットだけ」と「配信画面ぜんぶ」の切り替えが設定画面にもあり、URLを1本貼りたい人には関係を理解する必要がある（`public/dashboard/editor.js:2737-2773`）。今回の初回手順ではこの切り替えを変更しなかったので、影響は迷いとしての推測。

### 細かい

1. URL一覧の各行に「コピー」と「設定」が並び、配信ソフトへ入れるだけの人にも設定ボタンが見える（写真 `/tmp/first-run-walk/390-02-url.png`、描画は `public/dashboard/editor.js:873-880`）。

## 次に直す1つ

②の URL 画面を先に直す。理由は、①と③は目的・押すもの・済みの印が1つの流れで見えるのに、②だけは29行の中から選ぶ判断が残るから。これは今回の画面から分かる「迷う」であり、利用者が増えない原因とは断定しない。

次のカードの完成条件は次のとおりにする。

- 空データで、幅390と幅1280を①→②→③の順に歩く。
- ②では、①で選んだウィジェットの URL が最初に分かり、コピー後に「コピーした」と分かる。
- URLを貼る案内文と幅・高さを残す。
- 選んでいないウィジェットの URL は「ほかの URL」へまとめ、初めての人が最初に選ぶ必要をなくす。
- 同じ kind-ui の4つの問いを全画面で はい にする。LIVE Studio本体は別途「確かめていない」と書く。
