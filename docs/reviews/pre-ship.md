重い順に5つです。`npm test` は 290 件すべて通りました。

1. **昇格が見た目に効いていません**(`public/widgets/lib/cutin.js:446-451`、AC-7)。`result.from` は白い光と「ピキーン」を鳴らすだけです。最初から最終の段階で描き、`from` の段階から上の段階へ色・文字・写真を切り替える処理がありません。カードの「文字・色・写真が上の段階に変わる」を満たしていません。光って音が鳴るのに何も変わらない、という画面になります。
2. **プレミア柄が一部のスタイルで出ません**(`cutin.js:358-390`)。柄を入れているのは通常の筆の帯(`else` 側)だけです。縦長フレーム(`hatch`)と写真の帯(`style === 'photo'`)には柄の処理がありません。カードは「縦長は上下の縞の場所、写真の帯は縁の色の線」に入れるとしています。`premiumRate: 100` にしても出ません。
3. **サーバーの `cutinDraw` が無いとき、帯の形が毎回同じになります**(`cutin.js:343`)。以前は `Math.random()` で seed を引いていました。今は `cutinDraw` が無いと seed が常に 1 です。古いサーバー、ダッシュボードのプレビュー、見本が対象で、毎回同じ筆の形になります。カードの「既定は今と同じ見た目」に反します。`cutinDraw` が無いときだけ従来のランダムに戻すのが安全です。
4. **虹の格上げで「キュイン」が2回鳴ります**(`cutin.js:446-458`)。昇格の `sfx('kyuin')` に続いて、虹の `freeze` 側の `sfx('kyuin')` も鳴ります。`from` があって虹で `freeze` のとき、音が重なります。
5. **`prepare` の listener が例外を投げると配信が止まります**(`src/hub.js:86`、`src/runtime.js:106`)。`emit('prepare')` は `publish` の先頭にあり、try で囲んでいません。例外が出ると、そのギフトは集計にも画面にも届きません。`drawCutin` は単純なので今は起きにくいですが、共有の入口なので `try/catch` で囲む方が安全です。
