# レビュー: roulette-one-url 

**問題あり**(`npm test` は 294 件すべて成功。落ちたものはなし)
1. **画面の証拠がありません。** カードは「OBS に入れる URL」の撮影(1280・390)を求めていますが、`artifacts/` 自体がありません。ダッシュボードの見た目は誰も確認していません。
2. **カードのテスト置き場とずれています。** カードは `test/roulette-one-url.test.js`、実際は `test/acceptance/roulette-one-url.test.js` です。
3. **AC-3 と AC-4 のテストが弱いです。** どちらも `editor.js` や `simple.js` に文字列が含まれるかを見るだけです。
   - 個別 URL が「ほかの項目」の中に実際に出ること、`ids=` が付くことは確かめていません。
   - 「ほかの項目」は既定で閉じています。その中に置かれることも確認されていません。
4. **個別 URL の置き場所が壊れる恐れがあります。** `editor.js:2038` の `renderRouletteUrls` は、そのとき `.more.others .settings` が DOM にあれば中に入れます。無ければ `sizeHint` の隣に置きます。
   - フォームを作り直したあと、箱の場所が前と同じになる保証はありません。
   - 呼び出し順によっては、折りたたみの外に出たり消えたりします。
   - 実機で確認されていません。
5. **カードに無い変更が混じっています。** `src/config.js` の `widgetList` が、返す配列の `find` を `Object.defineProperty` で差し替えています。
   - 一覧に出さない個別行を `find` だけで拾う仕組みで、カードの「触ってよいもの」にありません。
   - 配列をコピーしたり JSON にしたりすると消えます。
   - 一覧と `find` の結果が食い違い、後でこの関数を触る人が混乱します。
   - 実際に必要なのは、`editor.js` の `currentWidget` を `'*'` に変えたことだけです。
6. **AC-4 の文で、元の説明が消えています。** `simple.js` の `roulettes.desc` を、元の「ギフトで回る、罰ゲームやごほうびのルーレット」から置き換えました。
   - この文は、ルーレットを持っていない人にも「ウィジェットを追加」のカード一覧(`editor.js:502`)に出ます。
   - 「この1本です」が何を指すのか分からなくなります。
   - 簡易表示以外では `def.desc` が使われるので、AC-4 の説明が出ません(`editor.js:739`)。
7. **プレビューの動作が変わっています。** ルーレットのタブのプレビューと URL 欄は、選んだ1個ではなく「全部」の URL(`ids` なし)になりました。カードには書かれていません。
AC-1(一覧・CLI)、AC-2(サイズ)、AC-5(`all.html`)は、コードとテストで確認できました。
