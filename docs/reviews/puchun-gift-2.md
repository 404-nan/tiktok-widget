# レビュー: puchun-gift 2巡目

**指摘（問題あり）**
1. 【直す】AC-2「見本ボタンで、その場で1回流せる」が作られていません。`puchunTestPlay`(`src/puchun.js:35`)は、テストからしか呼ばれていません。ダッシュボード(`editor.js`・`simple.js`)にも、サーバーの入口(API・WS)にも、見本ボタンはありません。`type: 'puchun'` を送るのは `runtime.js:209` のギフト経路だけです。
2. 【直す】AC-2「字(その演出のキー全部)を選べ」を満たしていません。字は JSON の textarea(`editor.js` の `type === 'object'`)です。演出ごとのキー(main、sub、say、num)の入力欄は出ません。選んだ演出に合うキーも教えてくれません。JSON を手書きする必要があり、`kind-ui` の方針にも合いません。間違えると「字の形は JSON で入力してください」と出るだけです。
3. 【直す】AC-3「順に流すことをダッシュボードに書く」が、画面上は見えにくい状態です。書いてあるのは `schema.js` の `desc` だけです。`puchuns` の項目(`texts` など)の `desc` は短く、「順に流す」とは書いていません。README には書いてあります。
4. 【直す】カードの「証拠」にある、スマホ幅とパソコン幅の画面(`artifacts/shots/`)がありません。`artifacts` フォルダ自体がなく、見る画面がありません。
5. 【軽い】`npm test` は 790 件中 787 件が通り、1 件が落ちました。落ちたのは `test/acceptance/obs.test.js:295` の「AC-4 返事が来ない(5秒)…」です。単独で 2 回流すと 41 件とも通ったので、全体実行のときだけ時間切れになる不安定なテストとみられます。puchun-gift の差分は obs には触れていません。ただ、`src/card-draw.js` の `#go` を「遅延 0 なら同期で `then()` を呼ぶ」に変えています。これはカードにない変更で、既存の card-draw の動きが変わります。
6. 【軽い】カードにない変更が 2 つあります。
   - `card-draw.js` の上記の変更(カードめくり)。puchun と関係がありません。
   - `README.md` の機能一覧に 2 行足しています(パチンコ演出と、パチンコ演出の本体)。カードは「1行」と書いています。
7. 【軽い】`puchun.html` は、演出が終わるまでの待ち時間を固定値(2.2/3.8/6.5/8 秒)で決めています。現状の演出の長さ(1.6/2.9/5.4/6.8 秒)より長いので、今は問題ありません。ただし、iframe の読み込み(フォントと `warm()`)が遅い PC では、演出の途中で iframe を消すことがありえます。演出の終了を受け取ってから次へ進む作りにはなっていません。
8. 【軽い】`entitlements` メッセージを受けた `puchun.html` はページを再読み込みします(`overlay.js:289`)。その間、待ち行列に残っていた演出は消えます。×200 の途中で管理者が設定を変えると、残りが流れません。
9. 【軽い】`widgetList` は `puchuns` の設定が 1 件でもあれば URL を 1 つ出します(`id: '*'`)。`entitled` の確認はありません。他の機能と同じなら問題ありません。
