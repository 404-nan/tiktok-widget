# スロット演出 デザイン仕様

モック: `docs/slot-design/mock.html`（6つの状態を縦に並べた静的ページ。リポジトリ直下に `node_modules` があれば書体も本番と同じになる）

対象: `public/widgets/slot.html` / `slot.js`（開示演出）と `src/slot.js`（結果はサーバーで先に決まる）。
この仕様は見た目と動きだけを決める。抽選・確率・景品はサーバー側の設定に従い、画面は結果を「どう見せるか」だけを受け持つ。

---

## 1. 置き場所と安全域

| 項目 | 値 |
|---|---|
| 配信の画面 | 縦 1080×1920 |
| ウィジェットの枠 | 1080×600（画面の下 3 分の 1。画面上の y=1320〜1920） |
| 筐体（本体） | 1032×480、枠の左 24px・上 8px に置く |
| 下の空き | 112px（枠内 y=488〜600）。TikTok の入力欄・ギフトボタンに隠れるので何も置かない |
| 左右の空き | 24px |
| 待機の小表示 | 376×112、右 24px・下 112px（筐体の下端と同じ線にそろえる） |

- TikTok の視聴画面では、コメントが **左下** にかぶる。そのため、送った人の札は帯の **右端** に置き、待機の小表示も右下に置く。
- スマホでは 1080px の画面が約 390pt 幅に縮む（約 0.36 倍）。**文字は 26px 以上**（約 9.4pt）にする。

## 2. 余白の規則

- 基準は **4px 刻み**。主に 8・12・16・24・28 を使う。
- 外側から順に: 筐体の縁 8px（金）→ 外側の墨線 4px（`box-shadow: 0 0 0 4px`。ぼかし 0）→ 内側の余白 12px。
- 部品と部品のすき間: 帯とリール窓 12px、リール同士 24px、リールとランプ 8px。
- リール窓の左右は 28px（停止位置の三角印 16px を置くため）、上下は 12px。
- 縁の太さの段: 筐体 8px ＞ リール 6px ＞ 帯・アバター 4px ＞ 残り回数 3px。太いほど外側。
- 角の丸み: 筐体 16px、待機の小表示 12px、リール窓 10px、帯 8px、アバター・残り回数 6px、リール 4px。

## 4. 色

グラデーション・半透明の面・ぼかしは使わない。すべて平らな 1 色。

| 名前 | HEX | 使いどころ |
|---|---|---|
| 墨 | `#111113` | 外側の線、リール窓、帯（回転中・はずれ）、絵柄の縁 |
| 白 | `#F6F5F1` | リールの表面、送った人の札、赤地の上の文字 |
| 赤 | `#D8121B` | 筐体の地、当たり線、7・チェリー、小当たりの帯 |
| 濃赤 | `#B00D16` | 金地・白地の上の赤い文字（金地で 4.56:1、白地で 6 以上） |
| 金 | `#FFC53D` | 筐体の縁、当たったコマ、停止ランプ、リーチ・大当たりの帯 |
| 薄金 | `#FFE08A` | 大当たりの帯の放射線だけ |
| 消灯 | `#3A3A40` | 消えている停止ランプ |
| にび | `#C9C9D1` | 「はずれ」の文字（墨地で 11.46:1） |
| リールの枠 | `#2A2A30` | リールの縁 |
| 回転中の面 | `#E9E7DF` | 回っているリールの表面（止まると白に戻る） |
| 絵柄の緑 | `#1E9E4A` / `#0B4F26` | スイカの地としま、チェリーの柄 |
| 絵柄の青 | `#1F5FD6` | リプレイ |

文字の見やすさ（WCAG の 4.5:1、大きな文字は 3:1 以上）:

| 文字 / 地 | 比 |
|---|---|
| 白 / 赤 | 4.79 |
| 金 / 墨 | 11.95 |
| 濃赤 / 金 | 4.56 |
| 白 / 墨 | 17.29 |
| にび / 墨 | 11.46 |

赤い文字を金地に置くときは、赤（3.31）ではなく必ず濃赤を使う。

### 期待度の色（段階を固定する）

| 段階（tier） | 帯の地 | 帯の文字 | ほか |
|---|---|---|---|
| はずれ `lose` | 墨 | にび | 光らせない |
| 小当たり `small` | 赤 | 白（墨の落ち影 5px） | 当たったコマを金に |
| 大当たり `big` | 金 | 濃赤 | 当たったコマを金に |
| ジャックポット `jackpot` | 金＋薄金の放射線 | 濃赤 72px | 筐体の縁が金と白で点滅 |

モックの「大当り」はいちばん強い見せ方（`jackpot`）で描いている。`big` は放射線と縁の点滅を省いたもの。

## 5. 文字

| 用途 | 書体 | 大きさ / 太さ |
|---|---|---|
| ひと言（回転！・リーチ！・小当たり・大当たり） | Dela Gothic One | 60px（リーチ 64px、大当たり 72px）、字間 0.04em、行の高さ 1 |
| はずれ | Zen Kaku Gothic New | 52px / 900（叩きつけない。落ち着いた書体にする） |
| 名前 | Zen Kaku Gothic New | 34px / 900、長いと「…」で切る |
| ギフト名と個数 | Zen Kaku Gothic New | 26px / 700、濃赤 |
| 残り回数 | Zen Kaku Gothic New | 26px / 900 |
| 待機の文字 | Zen Kaku Gothic New | 32px / 900 |

- 代わりの書体: Hiragino Sans → Noto Sans JP → Yu Gothic UI → Meiryo。
- ひと言は帯のいちばん大きな文字。1 画面で目に入る大きな文字は 1 つだけにする。
- 表示する言葉:
  - 回転中「回転！」、リーチ「リーチ！」、復活「復活！」
  - 結果は `payout.text` をそのまま出す（初期値は「はずれ」「小当たり」「大当たり」「ジャックポット」）
  - 待機「（ギフト名）で回せ！」、残り回数「あと N 回」（`pending` が 1 以上のときだけ）
- ギフト名は `giftDisplayName`（`src/gift-names-ja.json`）で日本語にする。モックの「バラ」は GiftID 5655。英語名を書かない。
- 開発用の文字（ID・状態名・ミリ秒など）は画面に出さない。

## 6. 絵柄（インライン SVG 6 種）

すべて `viewBox="0 0 100 100"`、墨の縁 5〜6px、平らな色。`<symbol>` に 1 回だけ書き、`<use href="#s-…">` で使う。

| ID | 絵柄 | 色 |
|---|---|---|
| `s-7` | 7 | 赤の地・墨の縁・上に金の線 |
| `s-bar` | BAR | 墨の板・金の縁・白い線で描いた文字（書体に頼らない） |
| `s-bell` | ベル | 金・墨の縁・白い光の線 |
| `s-suika` | スイカ | 緑の玉・濃緑のしま |
| `s-cherry` | チェリー | 赤い実 2 つ・緑の柄と葉 |
| `s-replay` | リプレイ | 青の板・白い回る矢印 |

設定の絵柄名との対応: `7`→7、`BAR`→BAR、`ベル`→ベル、`スイカ`→スイカ、`チェリー` と `さくらんぼ`→チェリー、`リプレイ`→リプレイ。
対応がない名前（いまの初期値の「スター」など）は、白い面に墨の 28px / 900 の文字で名前を出す。
→ 初期値の絵柄は、この 6 種にそろえるのがよい（設定の変更は別の作業）。

| リーチ | 金と赤で点滅「リーチ！」 | 1・2 本目が中段 7 で停止、3 本目はゆっくり回り金と赤の縁 6px が点滅、三角印が金 | 1・2 点灯 |
| 小当たり | 赤地に白「小当たり」 | 中段が金（例: チェリー・チェリー・ベル） | すべて点灯 |

## 8. 動き（ミリ秒）

基準は設定の `reelStopMs`（初期値 700）。t=0 はサーバーの `start` を受け取った時刻。
動かすのは `transform`（`translateY` / `scale` / `rotate` の関数）、`opacity`、色だけ。点滅は 1 秒に 3 回まで。

| 時刻 | 動き | 長さ / 曲線 |
|---|---|---|
| 0 | 待機の小表示が縮んで消える（scale 1→0.8、opacity 1→0） | 160ms ease-in |
| 0 | 筐体が下からせり上がる（translateY 600px→0） | 280ms `cubic-bezier(.2,.8,.2,1)` |
| 0 | 3 本が回り始める。1 周 6 コマ＝552px を下向きに | 1 周 240ms、linear |
| 120 | 帯「回転！」を叩きつける（scale 1.4→1） | 160ms ease-out |
| 700 | 1 本目が止まる。下に 10px 行き過ぎて戻る。ランプ点灯 | 120ms |
| 1400 | 2 本目が止まる（同じ動き） | 120ms |
| 1400 | **リーチのとき**: 帯を「リーチ！」に替えて叩きつけ、3 本目を 1 周 600ms に落とす。帯と 3 本目の縁を点滅 | 叩きつけ 160ms、点滅 1 周 400ms（1 秒に 2.5 回） |
| 2100 | 3 本目が止まる（`reelStopMs`×3） | 120ms |
| 2220 | 結果を出す（下の表） | |
| 3900 | サーバーの `done`（`reelStopMs`×3＋1800） | |
| done＋1200 | 次がなければ筐体が下へ戻り（translateY 0→600px）、待機の小表示が戻る | 240ms ease-in ／ 200ms ease-out |

結果ごとの動き（t=2220 から）:

| 結果 | 動き |
|---|---|
| はずれ | 帯をそのまま切り替える（叩きつけない）。点滅なし |
| ニアミス | 3 本目は当たり絵柄が中段の 1 コマ上で止まる。止まる直前の 1 コマだけ 1 周 600ms に落として「惜しい」を見せる |
| 小当たり | 帯を叩きつけ（scale 1.4→1、160ms）。中段の金を 2 回点滅（250ms 点灯 / 250ms 消灯）してから点けたまま |
| 大当たり（big） | 小当たりと同じ。帯は金地 |
| ジャックポット | 筐体の表面全体を白で 80ms 光らせる（1 回だけ）→ 帯を叩きつけ（scale 1.6→1、200ms）＋筐体を左右 ±6px で 3 回揺らす（240ms）→ 放射線を 1 回転 6000ms で回し、縁を 500ms ごとに金と白で替える（1 秒に 2 回） |
| 復活 | 3 本目ははずれの絵柄で止まり、帯は 900ms 何も出さない（溜め）→ 筐体を白で 80ms 光らせ、3 本目を 1 コマ下へ落として当たり絵柄にする（160ms）→ 帯「復活！」を 600ms → `payout.text` に替える |

続けてギフトが来たとき（`pending` あり）は、筐体を戻さずに次の回転へ入る。帯は「回転！」から始め直し、残り回数を 1 減らす。

## 9. 作るときの決まり

- **Chromium 103 で動くこと。** 使わないもの: `:has()`、`translate:` / `scale:` / `rotate:` の個別プロパティ（104 から）、コンテナクエリ、`color-mix()`、CSS の入れ子、`text-wrap`。`transform` は関数で書く。
- 絵柄はインライン SVG。外の画像・CDN を使わない。書体は `node_modules` から配る（`/widgets/lib/fonts.css` と同じ形。Dela Gothic One も足す）。
- アバターは TikTok の画像を 60×60 の角丸 6px で切り抜く。読み込めないときは名前の 1 文字目を金地に墨で出す（モックはこの形）。
- 名前が長いときは「…」で切る。ギフト名も同じ（待機の札は最大 166px）。

## 10. 実装の前に決めたいこと（今のコードとのずれ）

- `src/slot.js` の `hasReach` は「1 本目＝2 本目」か「2 本目＝3 本目」でリーチにする。後者は 3 本目が止まるまで画面では見えないので、画面は **1 本目と 2 本目が中段でそろったときだけ** リーチ演出を出す。
- 結果を見せる時間が短い。いまは 3 本目の停止（2100ms）から `done`（3900ms）まで 1800ms で、復活があると結果は約 900ms しか見えない。サーバーの待ち時間を `reelStopMs`×3＋2600 にすると、復活でも 1.5 秒以上残る（`src/slot.js` の変更は別の作業）。
- いまの `slot.js` のニアミスは「別の絵柄を出してから 650ms 後に本当の絵柄へ差し替える」形。この仕様では差し替えず、止まる位置（1 コマずれ）で見せる。

## 11. 自己批評 → 改訂した点

最初の版を Chromium で撮って見直し、次の点を直した。

1. **送った人の札が左にあった → 右へ移した。**
   TikTok の視聴画面ではコメントが左下にかぶる。いちばん大事な「誰のギフトで回ったか」が隠れるので、帯の右端に移し、ひと言を左にした。待機の小表示も右下に置いている。
2. **文字が小さすぎた → 最小 26px にした。**
   最初はギフト名と残り回数が 22px、名前が 30px だった。スマホでは約 0.36 倍になり、22px は約 8pt で読めない。名前 34px、ギフト名・残り回数 26px に上げ、札の幅を 300px から 320px に広げた。
3. **待機の小表示で「で回る」がはみ出していた → 2 行にした。**
   1 行目をギフト名の札、2 行目を「で回せ！」にした。札の幅を 376px にし、小リールを 52px から 48px に縮めた。長いギフト名は「…」で切れる。
4. **回転中の 3 本がまったく同じ絵に見えた → ずらし方を直した。**
   並びの始まりと開始の遅れの両方をずらしていたため、打ち消し合って 3 本がそろっていた。並びは同じにし、遅れ（-80ms・-160ms）だけでずらした。
5. **止まっているリールと回っているリールの区別が弱かった → 「ぶれ」を足した。**
   静止画では縦に伸ばすだけでは止まって見えた。回転中は表面を `#E9E7DF` に、絵柄を不透明度 0.55 にして、止まった瞬間に白とくっきりした絵柄へ戻るようにした（文字ではないので半透明の禁止には当たらない）。
6. **筐体を枠の上端ぴったりに置いていた → 上に 8px 空けた。**
   外側の墨線 4px が枠の外に出て切れていた。筐体を上から 8px に置き、下の空きを 120px から 112px にした。
7. **金地に赤い文字が読みにくかった → 濃赤に替えた。**
   赤 `#D8121B` と金の比は 3.31 で、大きな文字の基準ぎりぎり。金地の文字は濃赤 `#B00D16`（4.56）にした。

まだ残る弱いところ:

- 小当たりと大当たりの差が、静止画では帯の色ぐらいしかない。差は動き（白い光・揺れ・放射線の回転・縁の点滅）で付けているので、実装したら動画で確かめる。
- コメントは右側にも長く伸びることがあり、リールの 1・2 本目はかぶる。ここは配信者が置く位置で調整してもらうしかない。
- Chromium 103 そのものでは確かめていない（手元は新しい Chromium）。使っている CSS は 103 で使えるものだけに絞った。
