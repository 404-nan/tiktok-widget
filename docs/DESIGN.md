# デザインと作り方の方針（このプロジェクトのセンス）

新しいウィジェットや演出、設定を作るときは、最初にこれを読んでください。
これまでの配信者（オーナー）とのやりとりで決まってきた好みと、作り方の約束をまとめています。

---

## 1. 言葉

- **配信者やオーナーが目にする文は、すべて日本語。** ダッシュボード、エラー文、README、設定の説明、Git のコミットメッセージ、途中経過の報告も日本語で書く（考えるのは英語でもよい）
- やさしい日本語で書く。専門用語・カタカナ語・英語の略語はできるだけ避け、使うときは何のことかを添える
- コードのコメントも日本語。周りのコードの書き方・コメントの量に合わせる

## 2. ふつうのウィジェット（通知・カウンター・目標など）

テレビ中継のテロップやスコアボードの文法で作る。「AI が作ったっぽい」見た目はいちばん嫌われる。

- 面は不透明。ぼかし・発光・意味のないグラデーションで飾らない
- 色は **墨 #111113・白 #F6F5F1・朱 #FF4F1F・金 #FFC53D** の4色が基本。朱は「今起きたこと」、金は「コイン・達成」にだけ使う
- 書体: 和文 Zen Kaku Gothic New、数字 Barlow Condensed、パチンコ系の叩きつける文字は Dela Gothic One
- アイコンは Lucide（CSS の mask で文字色にする）。**飾りのためだけの丸いアイコンを横に置かない**（「横の適当なアイコンいらない、邪魔でしかない」と言われた）
- 動きはワイプ（clip-path）、文字のせり上がり、桁ごとに回る数字

## 3. 脳汁系の演出（カットイン・RUSH・WIN数の演出など）

パチンコの演出を手本にする。オーナーの言葉では「ドパる」「脳汁ドパドパ」。

- **溜めてから放つ**: 一瞬止める・暗転する・無音にする → 叩きつける。音量より「落差」
- **色で期待度を覚えさせる**: 青 < 緑 < 赤 < 金 < 虹。金額や規模を段階に固定する
- **段階的に上げる**: 続けて来ると1段ずつ派手に（連続妨害 ×3 で1段、など）。配信の規模に合わせて境目を選べるようにする（-1 しか来ない配信もある）
- **情報は最小限、刺激は最大限**: 画面に出す文字は「+100」「CLEAR」「WIN -10」など数字かひと言だけ。その分を光・色・音・揺れ・ひび・破片・紙吹雪で押す
- **主役は送った人**: 送った人のアイコン（必要なら名前）を出す。「自分のギフトで画面が変わった」体験を作る
- **筆・木炭のかすれ**: 帯の縁は筆でかすれた線（`public/widgets/lib/brush.js`）。オーナーが気に入っている質感
- 点滅は1秒に3回まで（目に優しく）
- 効果音は WebAudio で合成する（音源ファイルを使わない）: ドン、フィーン、ガガガ、キュイン、ドゴン、ガラスの割れる音、サイレン、ファンファーレ…

## 4. ダッシュボード・管理画面

- Hark 風のガラス素材（2色＋不透明度、なめらかな角、押したときのバネ）。`anthropic-skills:glass-dashboard-style` を参照
- 配信中にスマホでも押せるよう、よく押すボタンは大きく

## 5. 作り方の約束

- **設定は `config.yaml`、定義は `src/schema.js`。** 項目・初期値・説明（日本語）を schema に書くと、検証・ダッシュボードのフォーム・AI 向けの説明（MCP / CLI）に全部使われる
- 設定ファイルは書き換えてもコメントが残る（yaml の Document API）。`config.example.yaml` は読み込んで書き戻しても同じ文字になるよう保つ（テストあり）
- **状態はサーバーで持ち、WebSocket で配る。** OBS を読み込み直しても続きから出せるようにする（RUSH・WIN数・ルーレットの抽選など）
- 外部の CDN を使わない。フォント・アイコン・ライブラリは `node_modules` から配る（OBS がオフラインでも崩れない）
- テストは `npm test`（node --test）。見た目は Playwright でスクリーンショットを撮って確かめる（Chromium は入っている）
- 配信者が押すボタン・URL（Stream Deck から GET で叩ける）・AI（MCP / CLI）のどこからでも同じ操作ができるようにする

## 6. 妨害マイクラ

- 視聴者がギフトで Minecraft の配信者を妨害する配信。演出は **SuperStream**（Minecraft プラグイン）と RCON で起こす（`src/minecraft.js`・`src/superstream.js`・設定の `minecraft.rules`）
- **WIN数** はゲームのクリア回数（PK バトルではない）。クリアでボタン +1、ギフトのルールで増減（`{gifts: [Lion], add: -1}`）、マイナスまで行く。大きく減ると 大妨害 → 超妨害 → 壊滅、増えると 大 → 超 → 最大、目標達成はいちばん派手
- 配信によって -10・-100・-1000 WIN もある。規模はプリセット（`lossPreset` / `gainPreset`）で合わせる

## 7. これまでのフィードバック（抜粋）

- 「AI っぽいデザインじゃなく、まともなデザイナーが作ったレベルに」
- カットインの筆の帯と文字は好評。写真付きは写真の帯の縁が木炭でガシガシかすれる形
- 「通常カットイン」と「画像付きカットイン」は分ける
- RUSH はサイドに虹色の光のシャワーと筆っぽい線、「RUSH中」がはっきり分かるように
- WIN数は PK じゃない。リセットもできるように。マイナスも。マイナスをドパらせる
- 「情報は最小限で最大限の脳への負荷をかける」
