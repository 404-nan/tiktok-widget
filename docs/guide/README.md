# ライコネの使い方

TikTok LIVE の配信に、ギフトで動く演出を足す道具です。配信ソフトに URL を貼るだけで始められます。
難しい設定は要りません。スマホで読めるように短く書いています。

はじめてなら、上から順にどうぞ。

1. [はじめて使う](getting-started.md): URL を1本入れて、つないで、テストで動かすまで
2. [配信テンプレートを選ぶ](templates.md): 配信の種類を選ぶと、必要な設定がそろいます
3. [ウィジェットの紹介](widgets.md): 何が起きるか、どんな配信に向くか、大事な設定
4. [配信中にスマホで変える](phone.md): 手元で押せるボタンと、押すだけの URL
5. [TikTok につなぐ](connect.md): つなぎ方、TikFinity など別の道具から送る方法、OBS 連携
6. [困ったとき](faq.md): よくある質問と、うまくいかないときの直し方

更新のお知らせは [docs/news](../news/2026-10-v1.md) にあります。

## 読む前に

- 「近日」と書いてあるものは、まだ配信者のみなさんには出していない機能です。出たらこの文書の印を外します。
- 画面の名前は、ダッシュボードに出ている文字のまま書いています。
- 配信中に試すテストは、画面に出るだけです。コインの数やランキングは変わりません。
