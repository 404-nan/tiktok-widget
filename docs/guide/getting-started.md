# はじめて使う

流れは3つだけです。配信ソフトに URL を1本入れる、TikTok につなぐ、テストで動かす。10分あれば終わります。

## 1. ダッシュボードを開く

もらった短い URL を開いて、4桁の数字を入れます。一度入れた端末では、しばらく数字なしで開きます。

## 2. 配信ソフトに URL を1本入れる

TikTok LIVE Studio でも OBS でも、やることは同じです。

1. ダッシュボードの左で「OBSに入れるURL」を開く
2. 「1つにまとめる」の URL を「コピー」する
3. 配信ソフトで「ソースを追加」→「ブラウザ」を選び、URL 欄に貼る
4. 幅と高さは、URL の下に出ている数字に合わせる

これで、ほかの演出も同じ1本から出せます。ウィジェットごとに別のソースを作る方法もありますが、最初は1本のほうが楽です。パソコンも軽く済みます。

ルーレットが何個あっても、URL は1本で足ります。ギフトが来たルーレットが順番に出ます。(近日)

## 3. TikTok につなぐ

ダッシュボードの左上に、自分の TikTok ユーザー名を入れて「接続」を押します。

- @ は付けません
- つなげるのは、配信が始まっているときだけです
- つながると、ギフトやコメントが届き始めます

つながらないときは [困ったとき](faq.md) を見てください。

## 4. テストで動かす

配信の前に、見本のギフトで動きを見ておくと安心です。

1. ダッシュボードで使いたいウィジェットを開く
2. 「ためす」の「見本のギフトを出してみる」を押す
3. 配信ソフトのプレビューに演出が出れば成功

配信中(TikTok につないでいる間)のテストは、画面に出るだけです。コインの数、ランキング、記録は増えません。つなぐ前に試して増えた数は、つないだときに 0 に戻ります。

## 5. 出すものを選ぶ

左の「出すものを選ぶ」で、使うものにチェックを入れます。外しても設定は消えません。いつでも戻せます。

何を選べばいいか分からなければ、[配信テンプレート](templates.md)を使うと、配信の種類に合わせてまとめて決まります。
