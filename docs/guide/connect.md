# TikTok につなぐ

ギフトやコメントを受け取る道は3つあります。ふつうは1つ目だけで足ります。

## 1. ユーザー名でつなぐ(ふつう)

1. ダッシュボードの左上に、TikTok のユーザー名を入れる(@ は付けない)
2. 「接続」を押す

配信が始まっているときだけ、つながります。つながったら、見本ではなく本物のギフトが届き始めます。

## 2. ほかの道具から送る(近日)

TikFinity や Streamer.bot をすでに使っているなら、そこからギフトなどをライコネに送れます。TikTok に直接つなげなくなったときの、もう1つの道にもなります。

### 鍵を作る

1. ダッシュボードの「外部ツール」を開く
2. 「鍵を作る」を押す
3. 出てきた URL をコピーする

この鍵は、作ったその1回だけ表示されます。ページを読み込み直すと消えるので、道具に貼るまで閉じないでください。なくしたら、作り直せば古い鍵は使えなくなります。

鍵は他人に見せないでください。ダッシュボードの URL とは別物で、これでダッシュボードは開けません。

### 道具に貼る

道具の「URL を呼ぶ」「Webhook」などの欄に、コピーした URL を貼ります。送る内容は、次の種類に分けます。

| 種類 | 送るもの |
| --- | --- |
| gift | ギフト(ギフトの名前、コイン、個数、送った人) |
| like | いいね(今回の数) |
| follow | フォロー |
| comment | コメント(本文) |
| share | シェア |

くわしい貼り方は、ダッシュボードの「外部ツール」に、そのままコピーできる形で出ます。

### 二重に数えない

直接つないだ道と、外部ツールの道から、同じギフトが来ることがあります。ライコネは同じ内容を見つけて、片方を捨てます。ギフトが2倍になることはありません。

### つながり具合を見る

「外部ツール」に、どの道が生きているかと、最後にいつ届いたかが出ます。

### 試す

送るときに「テスト」の印を付けると、画面に出るだけで、数は増えません。

## 3. OBS のカメラを動かす(近日)

虹の演出や大当たり、ボス討伐のとき、OBS の映像を揺らしたり、拡大したり、シーンを切り替えたりできます。ふつうの演出より迫力が出ます。

初めはオフです。使うときだけオンにします。

### 準備

1. OBS の「ツール」→「WebSocket サーバー設定」で、サーバーを有効にする
2. ダッシュボードで OBS 連携をオンにして、揺らしたいカメラのソース名を入れる
3. OBS に「ブラウザ」ソースを足し、ライコネが出した URL を貼る
4. その URL の最後に、`#pw=` と OBS のパスワードを自分で足す

### パスワードについて

`#pw=` のあとに書いたパスワードは、ライコネのサーバーに送られません。ブラウザが、`#` から後ろを送らないためです。サーバーにも、設定にも、記録にも残りません。

ただし、OBS のソースの設定画面に書いた URL には残ります。配信画面にその画面を映さないでください。

### 動きが強すぎるとき

「弱めにする」をオンにすると、揺れと拡大が半分くらいになります。画面の明るさは変えないので、点滅はしません。

OBS につながらないとき、パスワードが違うときは、何も起きません。配信は止まりません。

## どの道を使えばいいか

- 迷ったら 1 だけ
- 配信中にときどき止まるなら、1 に 2 を足す
- 映像を動かしたいなら、3 を足す
