# 配信テンプレート

設定を1つずつ覚えなくても、どんな配信をするかを選ぶだけで、必要なウィジェットと設定がそろいます。(近日)

## 3つから選ぶ

| テンプレート | こんな配信 | 山場 |
| --- | --- | --- |
| 妨害マイクラ | 配信者がマイクラをクリアしようとして、視聴者がギフトで邪魔をする | 大きな妨害、WIN 数の目標達成 |
| 罰ゲーム雑談 | 雑談しながら、ギフトでルーレットを回して罰ゲームを決める | 激辛や恥ずかしい罰が当たる瞬間 |
| 耐久・目標配信 | 目標に届くまで終われない。ギフトで残り時間が延びる | 目標達成、残り時間ぎりぎり |

迷ったら、いまの配信にいちばん近いものを選んでください。あとから1つずつ変えられます。

## 入れる前に、何が変わるか見る

テンプレートを選ぶと、押す前に変更の一覧が出ます。

- どのウィジェットが増えるか
- どの設定が、いまの値から何に変わるか
- 管理者が許可していなくて、入らないもの(豪華な演出など。「入れない」と表示されます)

見て、よければ「入れる」を押します。気に入らなければ何も押さずに閉じてください。この時点では何も変わっていません。

## 入れたあと

- すぐに配信画面に反映されます
- 合わなければ「元に戻す」で、入れる前の設定に戻ります
- 入れたあとに自分で設定を変えていた場合は、勝手に戻しません。戻したいときは、変えたところを自分で直してください

いまの設定を黙って消すことはありません。同じ名前のルーレットがあるときは、「今の項目 → 新しい項目」の形で見せてから入れます。

## 気をつけること

- マイクラとのつなぎ(接続先やパスワード)は、テンプレートでは変わりません。「マイクラ連携」の画面で自分で決めます。
- 数字(目標の数、ギフトごとの減らす数など)は目安です。入れたあとに、自分の配信に合わせて変えてください。
- 古くからある「初めて開いたときに選ぶ遊び方」は、そのまま残っています。テンプレートは別の入口です。
