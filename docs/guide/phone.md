# 配信中にスマホで変える

配信中は、パソコンの前にいられないこともあります。手元のスマホで、押すだけで操作できます。

## モニター画面を開く

ダッシュボードと同じ URL の仲間に、モニター画面があります。配信中に手元で見るための画面です。

- コインや視聴者の数
- 流れてきたコメントとギフト
- WIN 数、延長タイマー、RUSH のボタン
- ルーレットの待ちと結果
- 目標とトップギフター

見るだけでなく、ボタンで操作もできます。

## よく押すボタン

| やりたいこと | 押すもの |
| --- | --- |
| クリアで WIN を +1 | WIN 数の「クリア」 |
| 間違えたので戻す | 「戻す」 |
| タイマーを止める、動かす | 延長タイマーの「一時停止」「再開」 |
| 時間を足す、引く | 「+1分」「-1分」 |
| RUSH に入る、終わる | RUSH の「突入」「終了」 |
| ボスを回復する | ボス討伐の「HP を戻す」 |

リセットは、押すと確認が出ます。押し間違いでも、WIN 数は「戻す」で元に戻せます。

## ダッシュボードもスマホで使える

スマホでダッシュボードを開くと、上にボタンが並びます。プレビューが上に貼り付くので、変えた結果を見ながら決められます。

## 押すだけの URL(Stream Deck など)

操作ごとに、開くだけで動く URL があります。Stream Deck の「Webサイト」や、スマホのホーム画面のショートカットに入れておくと便利です。

URL はダッシュボードの「くわしく」の中に、実際の形で一覧が出ています。そこからコピーしてください。

## 配信中に気をつけること

- 配信中は、設定を大きく変えないほうが安全です。ボタンで押せる範囲にとどめてください。
- 新しい設定は、配信前に「ためす」で確かめます。
- OBS に入れた URL は、配信中に貼り直さないでください。映像が一瞬途切れます。

## 配信のあとで見る

「統計」の画面に、配信ごとの記録が残ります。1分ごとのコインと視聴者のグラフ、トップギフター、ギフトの内訳が見られます。

演出ごとに、そのあとギフトがどう変わったかを出す機能も入ります。(近日)
