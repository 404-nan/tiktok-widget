# ウィジェットの紹介

ウィジェットは、配信画面に重ねる1つ1つの演出です。ここでは「何が起きるか」「どんな配信に向くか」「最初に見てほしい設定」を書きます。設定は多くても3つまでにしています。ほかの項目は、初めのままで困りません。

「近日」は、まだ出していないものです。

## ギフトに反応するもの

### ギフト通知
- 起きること: ギフト、フォロー、シェアが来ると、テロップのように流れます。高額のギフトは金色になります。
- 向く配信: どんな配信でも。まず入れる1つ目におすすめです。
- 設定: 金色にするコインの数 / 出すもの(ギフトだけ、フォローも、など) / 秒数

### カットイン
- 起きること: 筆でかすれた帯が入って、文字が叩きつけられます。コインが大きいほど、青、緑、赤、金、虹と派手になります。
- 向く配信: 大きなギフトを盛り上げたい配信。
- 設定: 各色になるコインの数 / 音のオンオフ / 文字

### 画像付きカットイン
- 起きること: カットインの中に自分の写真が入ります。
- 向く配信: 顔やキャラクターを見せたい配信。
- 設定: 写真 / 形(帯の中いっぱい、帯の横) / 各色になるコインの数

### RUSH
- 起きること: 突入すると「RUSH突入」が出て、画面の左右に帯が流れます。中でギフトを受けるたびに時間が延びます。
- 向く配信: 盛り上がっているときに、もうひと押ししたい配信。
- 設定: 入るのに必要なコイン / 延びる秒数 / 最長の秒数

### ギフト瓶
- 起きること: 届いたギフトが瓶に落ちてたまっていきます。
- 向く配信: 静かな雑談で、ギフトが目で見えると嬉しい配信。
- 設定: 形(瓶、ハート、フラスコ) / 大きさ / 数える対象

### ルーレット
- 起きること: 指定のギフトが届くと回ります。丸型と横に流れる型があります。
- 向く配信: 罰ゲームやご褒美を決める配信。
- 設定: 回すギフト / 項目と当たりやすさ(2 にすると2倍当たりやすい) / 項目の色や画像

### スロット、ガチャ
- 起きること: ギフトで回して、当たりの大きさで演出が変わります。
- 向く配信: 運試しの時間を作りたい配信。
- 設定: 回すギフト / 当たりの種類 / 音

## 数字で見せるもの

### いいね・視聴者数
- 起きること: いいね、視聴者、フォロー、コインを数字で出します。
- 向く配信: 目で見て分かる数字が欲しい配信。
- 設定: 出す数字 / 大きさ / 色

### 目標バー
- 起きること: フォローなどの目標までの進み具合を出します。達成したら、目標を自動で上げられます。
- 向く配信: 目標を決めて進める配信。
- 設定: 何を数えるか / 目標の数 / 達成後に足す数

### ランキング
- 起きること: この配信のトップギフターが出ます。順位が入れ替わると、なめらかに動きます。
- 向く配信: 常連さんが多い配信。
- 設定: 何位まで出すか / コインかいいねか / 色

### 延長タイマー
- 起きること: 配信の残り時間が出ます。ギフトやフォローで時間が延び、残りが少なくなるとカウントダウンが出ます。
- 向く配信: 耐久配信、サブアソン。
- 設定: 始めの時間 / 1コインで延びる秒数 / 上限の時間

### ボス討伐
- 起きること: ギフトがダメージになって、みんなでボスの HP を削ります。倒すと次のボスが出ます。
- 向く配信: 視聴者みんなで1つの敵を倒したい配信。
- 設定: ボスの HP / 倒したあとに回すルーレット / 画像

### WIN 数
- 起きること: ゲームのクリア回数が出ます。ギフトで増えたり減ったりして、大きく減ると画面にひびが入ります。
- 向く配信: 妨害マイクラなど、勝ち負けのある配信。
- 設定: ギフトごとの増減 / 目標 / 演出の強さ

## 配信を回しやすくするもの(近日)

### ニュースティッカー
- 起きること: 画面の下に、お知らせ、目標の進み具合、最近のギフトが流れます。
- 向く配信: 長時間の雑談。
- 設定: 流す文 / 流す速さ / ギフトを流すか

### 最近のサポーター
- 起きること: 最近のフォローやギフトの人が、小さなカードで並びます。
- 向く配信: 来てくれた人にお礼を言いたい配信。
- 設定: 並べる人数 / 出すもの(フォロー、ギフト) / 消えるまでの秒数

### 初見さん・常連さんの入室
- 起きること: はじめて来た人や、何度も来ている人を、テロップで迎えます。
- 向く配信: 常連さんが育ってきた配信。
- 設定: 常連と呼ぶ回数 / 迎える文 / 出す秒数

保存するのは、元に戻せない番号と来た回数だけです。名前やアイコンは保存しません。

## 盛り上がりを作るもの(近日)

### コンボ
- 起きること: 同じ人が続けてギフトを送ると「×2」「×3」と数えて、段が上がるたびに色が変わります。
- 向く配信: もう1回送ってほしい配信。
- 設定: つながる秒数 / 数えるギフト / 段の境目

### ステップアップ
- 起きること: 短い時間に全員が送ったコインの合計で、STEP 1 から 5 まで1段ずつ上がります。少額の人も合計に入ります。
- 向く配信: みんなで1つの山を作りたい配信。
- 設定: 規模(小、中、大) / 1回の長さ / 待ち時間

### 群予告
- 起きること: 短い時間にギフトの数が増えると、ギフトの絵の大群が画面を横切ります。
- 向く配信: 小さなギフトが多く届く配信。
- 設定: 数える秒数 / 境目の数 / 音

### 王冠
- 起きること: 直近10分の合計が1位の人に王冠が乗ります。入れ替わりそうなときは、2人の対決画面が出ます。
- 向く配信: 首位争いが起きやすい配信。
- 設定: 数える期間 / 対決を出すか / 音

### ダレ場の事件
- 起きること: ギフトの勢いが落ちたときだけ、小さな事件が起きて空気を変えます。
- 向く配信: 盛り上がりに波がある配信。
- 設定: 落ちたと判断する目安 / 起こす事件 / 間隔

### 遅れて光るランプ
- 起きること: ギフトの直後ではなく、少し経ってから隅のランプが光ります。光った人が主役になります。
- 向く配信: 待つ時間もどきどきにしたい配信。
- 設定: 光るまでの時間 / 確率 / 色

### 最後の一投とエンドロール
- 起きること: ラスト10分を始めると、最後にギフトを送った人が大トリになります。終わるとき、来てくれた人の名前が流れます。
- 向く配信: 締めを盛り上げたい配信。
- 設定: ラストの長さ / エンドロールを出すか / 音

### リレー停止(スロット)
- 起きること: スロットの3つのリールを、ギフトを送った人が順番に止めます。
- 向く配信: 何人かで1つの結果を見届けたい配信。
- 設定: 使うスロット / 待つ時間 / 音

## コメントで参加できるもの(近日)

お金を使わない人も、配信に関われます。

### 投票
- 起きること: コメントで「1」「2」「3」と打つと、集計されます。時間が来たら結果が出ます。
- 向く配信: 次にやることを視聴者に決めてもらう配信。
- 設定: 選択肢 / 受付の長さ / 結果で動かすもの(ルーレットなど)

### 押せボタン
- 起きること: 「押せ!」が出て、コメントの「押」かいいねの連打で押します。押した量で青、緑、赤、金の結果になります。
- 向く配信: 全員で1つのことに挑戦する配信。
- 設定: 受付の長さ / 合言葉(「押」など) / 各結果で動かすもの

### 応援ゲージ
- 起きること: いいねがたまってゲージが伸び、満タンで演出が起きます。
- 向く配信: いいねをお願いしたい配信。
- 設定: 満タンまでのいいねの数 / 次の目標を何倍にするか / 満タンで動かすもの

## マイクラの配信向け(近日)

### ゴール接近の警報
- 起きること: 配信者とゴールの距離が50m、20m、5mになると、ゲームの中と画面の両方で警報が出ます。
- 設定: 警報を出す距離 / 音 / 見た目

### 送った人の名前入りの妨害
- 起きること: 妨害が起きるとき、ゲームの中に送った人の名前が出ます。効果はダメージなしです。
- 設定: 名前を出す場所 / 長い名前の切り方 / 使う妨害

## ウィジェットを自由に増やす

同じウィジェットは、名前を付けていくつでも作れます。たとえばルーレットを「罰ゲーム」と「ご褒美」で分けて持てます。
