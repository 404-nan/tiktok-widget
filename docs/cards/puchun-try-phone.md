## 完成の条件
- AC-1 書体の読み込みが失敗しても、または3秒たっても終わらなくても、演出の準備が終わる(`window.fxReady` が true になる)。書体が普通に読めるときの動きは変わらない。
- AC-2 ためす画面で、比率に 1:1 と 4:3 を選ぶと、見本の枠がその比率になる。9:16 などほかの比率は今までどおり。
- AC-3 幅390のためす画面で、見本が入力欄より上に見え、横にはみ出さず、入力欄の字が16px以上。
- AC-4 幅1280のためす画面の組み立ては今までと変わらない。

## 証拠
幅390と幅1280のためす画面の写真を `artifacts/shots/` に置く。レビュー役は写真が空でないことと、AC-2 の比率を確かめる。
