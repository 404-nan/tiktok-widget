# 週に1回、配信の記録をまとめて分析用に書き出す

目的: 全テナントの1週間の配信を1つにまとめ、ルー君の週次の分析に渡す。

完成の条件:
- AC-1 `npm run export:weekly -- --since <日付>` で、全テナントの配信の記録(合計、1分ごとの推移、ギフトの種類、上位のギフター、推定額)を1つの JSON にまとめる
- AC-2 視聴者の名前・ID は書き出しでは伏せる(順位と金額だけ)。配信者名はテナント ID にする
- AC-3 実データは読むだけ。書き出し先は引数で指定(既定 `artifacts/weekly/`)
- AC-4 1件も配信が無い週でも、空のまとめを出して終わる

作らないもの: 分析そのもの、グラフ、外への送信

決まっていないこと: なし

証拠: test/acceptance/(偽の配信の記録3件から書き出す)、npm run check
