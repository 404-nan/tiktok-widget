# gacha-viewers-demo: ガチャの視聴者の記録に、デモとテストの視聴者を混ぜない
for: 北極星
仕事の種類: 直す
見た目が変わるか: 変わらない(一覧に出る人が減るだけ。画面の作りは変えない)

なぜ要るか: 配信者がガチャの視聴者一覧や回数を見るとき、本物の視聴者とデモの人が混ざると、誰が何回引いたか信じられない。本番の記録で 22人中9人がデモやテストだった(docs/research/real-records-audit-2026-11-02.md は ops 側)。
前提: 読み取りでの見立て。src/runtime.js:217 の gachaViewers.onEvent(e) は、デモとテストのイベントも通す。ほかの記録には除く形がある(src/history.js:212、src/visitors.js:12 の isDemo)。
目的: デモとテストのイベントでは、ガチャの視聴者の記録が増えない。デモでガチャの演出を見ることは今までどおりできる。
触ってよい: src/runtime.js src/gacha-viewers.js test/* src/README.md README.md
触らない: 本番 3939、data/、config.yaml
作らないもの: 保存済みの記録の削除や書き換え、一覧の画面の作り替え、回数や確率のルールの変更。

## 完成の条件
- AC-1 再現テストを先に書く: test: true のイベントと、user.id が demo_ で始まるイベントを流しても、保存される視聴者の記録(人数・無料回・有料回)は増えない。直す前は失敗する。
- AC-2 本物の視聴者のギフトとコメントは、今までどおり記録され、回せる。
- AC-3 デモを動かしたとき、ガチャの演出は今までどおり出る(直す前と同じ入力で hub へ同じ演出が流れることをテストで確かめる)。
- AC-4 保存済みの記録に user.id が demo_ で始まる人がいても、視聴者の一覧を返す API には出さない。保存された中身は変えない。
- AC-5 npm test が全部通る。README のガチャの視聴者の行に「デモとテストは数えない」を足す。
