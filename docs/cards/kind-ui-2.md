# kind-ui-2: ダッシュボードを、パソコンが苦手な配信者でも迷わない形にする
仕事の種類: 作り込み
見た目が変わるか: 変わる(本番に出す前にオーナーが開発サーバーで見る)

考えた人: Claude(2026-10-24、オーナーの声と今の画面を見て)。前の直し(dev/kind-ui の 2db1764)は、中身がサイドバーの下に潜って左が切れ、「設定」がいちばん下ではなく真ん中にあった。それも直す。

## 誰が、いつ、何のために使うか

- 使う人: TikTok の配信者。ほぼ全員が TikTok LIVE Studio。パソコンが苦手。配信の直前に、スマホかパソコンで手早く触る
- やりたいことは4つだけ: (1) 配信ソフトに入れる(最初の1回) (2) 出すものを選んで、少し変える (3) 配信の前にためす (4) 配信中に様子を見る
- 今の画面の問題: 全部が1本の長いページに並んでいる / 開発者向けの言葉(Euler、API、MCP、テナント、トークン、YAML)が見える / システムの言葉(種類、動作、出すきっかけ、カンマ区切り)/ 同じことをする入口が2つある / ボタンの名前が「仕組み」の名前で、押すと何が起きるかが分からない

## 言葉の決まり(画面の全部の文字に当てる)

1. **見出しは質問か、名詞1つ。** 「いつ出す？」「どう見せる？」「大きいギフトのとき」
2. **ボタンは、押すと何が起きるかを動詞で。** 「保存」→「この名前にする」、「トークンを発行」→「AI 用の合言葉を作る」
3. **システムの言葉を使わない。** 開発者向けの言葉は「設定」の奥の「くわしい人向け」の中だけ

| 今 | これから |
| --- | --- |
| 種類 | プリセット |
| 出すきっかけ | どんなときに出す？ |
| ギフト名(カンマ区切り) | どのギフトで出す？(下の「ギフトをえらぶ」で選ぶ。カンマの説明は消す) |
| 何コインから出す | 何コイン以上で出す？ |
| 出しかた ひかえめ / ふつう / しっかり | 目立ちかた ひかえめ / ふつう / はでに |
| たての位置・よこの位置(プルダウン2つ) | 出す場所(3×3 のマスを押して選ぶ) |

4. **状態は人の言葉で。** 「配信につながっていません」「つないでいます…」「配信中」
5. **数字には単位と例をつける。**
6. **開発者向けの文は画面に出さない。** 例: サイドバーの「配信前は Euler を使わずに確認します。最初の30分は1分ごと…」は消す

## 画面の組み立て

### サイドバー(上から)

1. 配信者の表示名と、状態の丸(「配信中」など)
2. 「配信につなぐ」ボタン1つ(TikTok の ID は設定に入れておく。入っていないときだけ、ここで ID を聞く)
3. ホーム
4. 「配信に出すもの」: 使っているものの一覧 + 「＋ 出すものを増やす」
5. 配信中に見る(今のモニター)
6. これまでの配信(今の統計)
7. (空き)
8. いちばん下に、使い方 と **設定**。どの画面の高さでも、設定はいちばん下に固定する

### ホーム(今の長い1ページをやめる)

- 「配信の準備」の3つ: ①配信ソフトに URL を入れた ②出すものを選んだ ③ためした。済んだものには印
- お知らせ(更新のお知らせ)は、未読があるときだけ小さく
- プランは、お試しの期限が近いときだけ

### 1つのウィジェットの画面(例: ギフト通知)

- いちばん上の1行: 「ギフト通知」 + プリセットの切り替え `[ふだん用 ▾]` と「配信で使用中」の印
  - ▾ を開くと、プリセットの一覧 / 線 / 「＋ 新しいプリセット」/「名前を変える」/「このプリセットを消す」。**作る入口はここ1つだけ。** 横の「もう1つ作る」ボタンは消す
  - プリセットの名前をダブルクリックすると、その場で文字を直せる(Enter で決定、Esc でやめる)
  - 初めて開いたときだけ、下に小さく「プリセット = 設定のセット。配信ごとに切り替えられます」
- その下に1行の説明: 「ギフトやフォローが来たら、送った人の名前を画面に出します」
- 左: 設定のカード(質問の見出し)。右: 見え方のプレビュー、「ためしにギフトを1つ出す」、配信ソフトに入れる URL(コピー)、大きさ
- 「もっと細かく」は閉じておく。いちばん下に、目立たない文字で「ギフト通知を使わない」

### 設定の画面(サイドバーのいちばん下から)

1. 表示名と TikTok の ID
2. 画面の明るさ: `[ライト | ダーク]` の2つのボタン。3案(配信風など)はなくす
3. AI につなぐ: 1行の説明「Claude や ChatGPT から、ライコネの設定を手伝ってもらえます」+「AI 用の合言葉を作る」。API の URL・MCP・テナントの番号は「くわしい人向け」を開いたときだけ
4. くわしい人向け(閉じておく): 設定ファイル、AI の接続先の URL

## モーダル

- **名前を変える**: 画面の真ん中。見出し「名前を変える」、入力欄(今の名前が入っていて、全部選んだ状態)、ボタン「やめる」「この名前にする」。Enter で決定、Esc と外側を押したらやめる。開いたら入力欄にすぐ打てる
- **新しいプリセット**: 見出し「新しいプリセット」、入力欄「名前(例: 24時間耐久)」、選ぶもの「今の設定をもとにする / はじめから」、ボタン「やめる」「作る」
- ブラウザの prompt・alert・confirm は、ダッシュボードの中では使わない(消すときの確認は今回はそのまま)

## 完成の条件

- AC-1 上の言葉の表を全部当てる。`public/dashboard/` の画面の文字に、Euler・API・MCP・テナント・トークン・YAML・種類 が出ない(「くわしい人向け」の中は別)。テストで確かめる
- AC-2 サイドバーの順番が上のとおり。設定はどの高さでもいちばん下。「下にまだあります」「じゅんび」がない
- AC-3 中身がサイドバーの下に潜らない(PC 幅 1280・1440、スマホ幅 390 で、中身の左端がサイドバーの右端より右)。Playwright で確かめる
- AC-4 プリセットの作る入口は ▾ の中の1つだけ。ダブルクリックで名前をその場で直せる。名前の変更と新しいプリセットは真ん中のモーダル
- AC-5 見た目はライトとダークの2つだけ。設定の画面で切り替え、選んだほうを覚えておく
- AC-6 AI との接続はホームやウィジェットの画面に出ない。設定の画面の中だけ
- AC-7 ホームは長い1ページではなく、上の3つ(配信の準備・お知らせ・プラン)だけ
- AC-8 公開ウィジェット・設定ファイルの形(schema のキー)・API は変えない
- AC-9 npm test が全部通る。README を直す
