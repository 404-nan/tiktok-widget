# 配信中に TikTok から届いたデータを全部残す

目的: ウィジェットにつないでいる間に TikTok から届くデータを、あとで週次の分析に使えるよう、取りこぼさず配信ごとに残す。

完成の条件:
- AC-1 TikTok につないでいる間、届いたメッセージ(tiktok-live-connector の decodedData。今使っていない種類も含む)を、配信ごとに `<データ置き場>/sessions/<配信ID>.events.jsonl.gz` に1行1件で残す(届いた時刻、種類、中身)
- AC-2 テナントごとに分かれる(配信者Aのデータが配信者Bの置き場に入らない)
- AC-3 1配信の上限(既定 200MB、環境変数で変えられる)を超えたら、それ以降は書かずに「上限で止めた」を記録に1行残す。配信とウィジェットは止まらない
- AC-4 書き込みに失敗しても(ディスクがいっぱいなど)、配信とウィジェットは止まらない
- AC-5 つないだときのルーム情報(配信者名、ルームID、開始時刻)を記録の先頭に残す
- AC-6 デモ・テスト送信のイベントは残さない(本物の配信だけ)

作らないもの: 分析、画面、外への送信、古い記録の自動削除(別カード)

決まっていないこと: 残す期間(仮: 180日)/ 視聴者の名前・アイコンをそのまま残すか(仮: そのまま。外のAIには送らない)

証拠: test/acceptance/ の受け入れテスト(偽の接続で decodedData を流す)、npm run check
