# 配信の記録に、ダイヤ数と推定額を出す

目的: LIVE センターの「ダイヤモンド」「この LIVE の推定額」と同じものを、配信の記録で見られるようにし、週次の分析に使う。

完成の条件:
- AC-1 配信の記録(data/sessions/<id>.json)の合計に、ダイヤ数(今の coins と同じもの)と推定額(USD)が入る
- AC-2 推定額 = ダイヤ数 × 1ダイヤあたりの額。既定は 0.00408 USD(2026-10 の LIVE センターの実数2件から出した値)。環境変数で変えられる
- AC-3 LIVE センターの実際の数字(ダイヤ、推定額、総視聴数、新しいフォロワー、ファンクラブ)を、あとから配信の記録に手で足せる(管理画面か CLI。足した値は「実数」として推定と分けて持つ)
- AC-4 実数が入った配信が増えたら、1ダイヤあたりの額をその平均で出せる(CLI で表示)

作らないもの: 円への換算、税や手数料の計算、配信者向けの画面

決まっていないこと: 実数を入れる手間をどうするか(仮: 管理画面に入力欄。スクショから読み取るのは後で)

証拠: test/acceptance/、npm run check
