# mc-goal-alert: ゴール接近警報
仕事の種類: 作り込み
見た目が変わるか: 変わる

目的: 配信者とゴールの距離を安全に測り、50m・20m・5mの境目でゲーム内とウィジェットへ同時に警報を出す。最後の妨害チャンスを全員に分かる形にする。

## 作るもの(触ってよいファイル)
- 新規: `src/mc-goal-alert.js`、`test/acceptance/mc-goal-alert.test.js`
- 足す: `src/minecraft.js`、`src/rcon.js`、`src/schema.js`、`src/runtime.js`、`public/widgets/goal-alert.html`
- 新規テスト: `test/mc-goal-alert-wiring.test.js`

## 触らないファイル
- `config.yaml`、`data/`、既存のWIN数・ゴール達成処理・RCON接続情報、配信中のMinecraft。
- TNT、爆発、ブロック破壊、ダメージ、配信中の再起動・`/reload`・datapack再読み込みはしない。

## 完成の条件
- AC-1 ゴール座標が登録されていないワールドでは機能を無効にし、距離を推測しない。座標とワールド名は秘密情報と分け、画面やログに接続情報を出さない。
- AC-2 開発用サーバーへ1秒に1回だけ距離問い合わせを出す。前の問い合わせが1500msを超えたらその回を捨て、妨害コマンドの列を止めない。未処理の問い合わせは1件だけにする。
- AC-3 距離が50m以下で青、20m以下で赤、5m以下で金の段へ入る。5m以下では「最終防衛ライン」とする。境目は一度の問い合わせで判定し、同じ段は30秒以内に再通知しない。
- AC-4 距離が段の境目より5m以上遠くなるまで、同じ段を再武装しない。ゴールに近づいたり離れたりしても、警報の連打を起こさない。
- AC-5 20mと5mの初回は、ゲーム内ボスバーとウィジェットへ同じ段・距離・サーバー時刻を送る。ウィジェットは受信から300ms以内に距離を出し、0.2〜0.4秒以内に警報文を見せる。
- AC-6 入り0〜500ms、山500〜1500ms、抜け1500〜2000ms。20mの縁は赤く2回だけ点滅し、1秒3回を超えない。効果音はWebAudioで合成し、1回の表示は3秒以内。
- AC-7 ゴール到達は既存WIN処理へ1回だけ渡し、距離問い合わせの再試行で二重加算しない。ゴール前に妨害を受けた場合の「防衛成功」は、直近の妨害イベントがあるときだけ出す。
- AC-8 統合版でボスバー・距離・タイトル・警報音の見え方を、作る前に開発用サーバーで確かめる。確認記録がない間は本番へ接続しない。
- AC-9 開発用のテスト送信と距離モックは、本番のWIN数・履歴・Minecraftへ送らない。画面を再読み込みしても現在の段と距離をサーバーから復元する。
- AC-10 公開JavaScriptはES5、外部CDN・外部素材なし。表示文は日本語だけにし、右列と下を避ける。

## 状態と失敗時
- `disabled`、`measuring`、`alerted`、`goal`、`error` をサーバーで管理し、画面の推定距離だけで段を進めない。
- RCONの返事が空、距離が負、ワールドが違う場合は `error` にして警報を出さず、WIN数も触らない。
- 距離取得が失敗しても妨害コマンドのキューを止めず、次の1秒周期で再試行する。
- 同じ距離を返し続けても、段の通知は30秒に1回を超えない。
- ゴール到達を受けた後は距離問い合わせを止め、既存WIN処理の完了を待ってから `goal` にする。
- 再接続時は現在の段、最後の通知時刻、表示中の距離をサーバー時刻から復元する。

## 演出の境目
- 50mは小さな心臓音、20mは警報、5mは心臓音だけにし、音量の大きさで驚かせない。
- 20mの文は「ゴールまで 20m」、5mの文は「最終防衛ライン」とし、数字は現在距離へ更新する。
- 送った人が関係する防衛成功を出す場合も、名前は0.2〜0.4秒以内に見せ、安全化済み文字列だけを使う。
- 画面中央の大きな文字は1500ms以内に上へ退け、距離表示とゲーム映像を長時間ふさがない。
- 統合版で表示できない要素があった場合は、表示できるボスバーまたはアクションバーへ縮退する。
