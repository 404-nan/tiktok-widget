## 点検で見つかったこと

重さ4(配信で困る・先に進めない)
- スマホ(390)で画面がこわれている。サイドバーが半分を取り、中身が細い列に押し込まれて、文字が1字ずつ縦に並ぶ(「何コイン以上で出す？」「見本をずっと出す」など)。ギフト通知の画面に「接続の状態」「TikTok(直接)」「外部ツール(受け口)」「受け口の鍵を作る」が出ている。上に古いタブ(モニター・統計・設定)が残っている

重さ3(多くの人が迷う)
- プランとお知らせのカードが、サイドバーの外(ページのいちばん上)に、どの画面でも出る。いちばん上が「お試しの期間です。」だけの札
- 言葉の表が当たっていない: 「出しかた ひかえめ/ふつう/しっかり」(→ 目立ちかた ひかえめ/ふつう/はでに)、「OBS / TikTok LIVE Studio に入れる URL」(→ 配信ソフトに入れる URL)
- 「出す場所」が2つある(3×3 のマスと、「左」のプルダウン)
- プリセットが ▾ のメニューになっていない(大きな入力欄のような枠と、すぐ下に「このプリセットを消す」)。「配信で使用中」の印がない
- ボタンの文字が折り返す(「ためしにギフト/を1つ出す」「見本をずっと出/す」)
- 「どんなときに出す？」が2回続けて出る(見出しとカードの中)
- 使い方と設定が、サイドバーのいちばん下に固定されていない
- サイドバーの「配信につなぐ」ボタンの形がくずれている(左に寄って、ふちが切れている)
- 見え方のプレビューが、開いたときに空
- 設定の「AIとの接続」に API・MCP・テナント・トークンがそのまま出ている
- 前の報告は「仕様どおり」だったが、テストはホームの画面で、開発の言葉と1つの重なりしか見ていなかった

## 直すこと

1. 上の全部を直す
2. スマホ(幅 768px まで): サイドバーは閉じておき、左上の「メニュー」で開く(中身の上に重ねて出し、外を押すと閉じる)。中身は画面の幅いっぱい。古いタブは消す
3. 接続の状態・外部ツール(受け口)・受け口の鍵は、設定の「くわしい人向け」(閉じておく)の中へ移す
4. 言葉の辞書 `docs/words.md` を作る。表は「使う言葉 / 使わない言葉 / なぜ」。kind-ui-2 の表と、開発の言葉(Euler、API、MCP、テナント、トークン、YAML、JSON、種類、受け口、ルール など)を入れる。テストはこの辞書を読んで確かめる。AGENTS.md に「ダッシュボードの画面を作る・直すときは skill kind-ui の決まりに従い、言葉は docs/words.md に合わせる」を書く
5. 部品をそろえる: ボタンは3種類(主役・ふつう・目立たない)だけにする。`public/dashboard/README.md` に部品の一覧(ページの形、カード、ボタン3種類、モーダル、状態の印、下に出るお知らせ)を書き、全部の画面をそれに合わせる。ボタンの文字は折り返さない(入らないなら言葉を短くするか、ボタンを幅いっぱいにする)
6. 見え方のプレビューは、開いたときから見本を出しておく(初めの値でどう見えるかが分かるように)

## 完成の条件(機械の点検。Playwright で、PC 1280 とスマホ 390、ライトとダーク)

全部の画面を回る: ホーム、サイドバーの「配信に出すもの」の全部、配信中に見る、これまでの配信、使い方、設定。テストは `KIND_UI_PLAYWRIGHT=1` のときに回し、ふだんの `npm test` では飛ばしてよい(今の形のまま)。

- AC-1 辞書の「使わない言葉」が、どの画面にも出ない(「くわしい人向け」を開いた中は除く)
- AC-2 サイドバーと中身が重ならない。サイドバーと中身のほかに、外に出ているカードがない(プランとお知らせはホームの中身の中)
- AC-3 スマホで中身の幅が 340px 以上。1字ずつ縦に並ぶ文字がない(見えている文字の要素で、2文字以上あるのに、幅が1.5文字分より狭いものがない)
- AC-4 ボタンの文字が折り返さない(ボタンの高さが1行分)
- AC-5 スマホで押せるもの(ボタン、リンク、入力欄)の高さが 44px 以上
- AC-6 文字と背景のコントラストが 4.5:1 以上(ライトとダーク)
- AC-7 画面のボタンが、決まった3種類のどれか
- AC-8 使い方と設定が、画面の高さ 700・900・1200 のどれでも、サイドバーのいちばん下にある
- AC-9 公開ウィジェット・設定ファイルの形(schema のキー)・API は変えない
- AC-10 `npm test` と `KIND_UI_PLAYWRIGHT=1` のテストが全部通る。README を直す
