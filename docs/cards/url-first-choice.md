## 完成の条件
- AC-1 空のデータで1つウィジェットを作ると、URL の画面の最初の一覧に、作ったものの行だけが出る。
- AC-2 選んでいないものの URL は「ほかの URL」にまとめ、初めは閉じている。押すと開いて全部の行が見え、コピーできる。URL は1つも消えない。
- AC-3 作ったものが1つも無いときは今と同じ案内を出し、「ほかの URL」は開いた状態か案内の下で見える。
- AC-4 コピーを押すと、今と同じ「コピーした」の印が出る。貼る案内の文と、行の幅・高さは残す。
- AC-5 幅390と幅1280で横にはみ出さず、「ほかの URL」はキーボードで開ける。

## 証拠
幅390と幅1280の、閉じた時と開いた時の写真を `artifacts/shots/` に置く。レビュー役は写真が空でないことと、AC-1 の行が先頭にあることを確かめる。LIVE Studio に貼るところは確かめられないので「確かめていない」と書く。
