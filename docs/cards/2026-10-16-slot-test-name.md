# スロットのテスト送信で、回した人の名前を指定できるようにする

目的: スロットの見た目を確かめるとき、長い名前や記号の名前でも試せるようにする(今は「テストさん」固定)。

完成の条件:
- AC-1 開発環境で POST /api/dev/trigger に { target: "slot", name: "長い名前の配信者さん" } を送ると、スロットの結果の user.name が「長い名前の配信者さん」になる
- AC-2 name が無い・空文字・空白だけのときは、今までどおり「テストさん」になる
- AC-3 name の前後の空白は取り除く
- AC-4 開発環境でないときは今までどおり 403(テスト送信は開発環境だけ)
- AC-5 ほかの target(gacha、gacha-viewer、boss など)の動きは変わらない(既存のテストが緑)

作らないもの: 画面(ウィジェット)の変更、名前の長さの上限、アイコンの指定

決まっていないこと: なし

証拠: test/acceptance/ の受け入れテスト、npm run check
