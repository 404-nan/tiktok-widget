# active-label: 「配信で使用中」を本当のことを言う言葉にする

for: 北極星
仕事の種類: 直す(言葉だけ)
見た目が変わるか: 変わる(ラベルの文字だけ。色・形は今のまま)

目的: ダッシュボードの各ウィジェットの選択欄に出る「配信で使用中」は、`public/dashboard/editor.js:942` の `config.active[tab] === id`(配信ソフトの URL で出るのがこの設定)だけで付く。配信につないでいなくても出るので、配信者は「もう配信に出ている」と思い、配信ソフトに URL を入れずに終わる(puchun-dash-fix のレビュー1の2)。北極星(配信者が実際に使う)の手前で迷わせている。判定は正しいので変えず、言葉を判定に合わせる。

前提: 言葉は `docs/words.md` の表に合わせ、新しい言葉は表に1行足す。
