- AC-1 空のデータで起動した画面を、幅390と幅1280で、①→②→③の順に歩く。1画面ごとに kind-ui の4つの問い(何をする所と思うか、押すものが見えるか、押した先が分かるか、済んだと分かるか)に はい/いいえ で答え、写真のパスと押した回数を書く。

- AC-5 人の名前、ID、鍵を報告に書かない。
