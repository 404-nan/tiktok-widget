# dareba: ダレ場に起こす小さな事件
仕事の種類: 作り込み
見た目が変わるか: 変わる

目的: ギフトの勢いが落ちたときだけ、ライコネが小さな事件を1つ起こす。冷えたことは画面に出さず、配信者の操作なしでも次の山を作る。

## 作るもの(触ってよいファイル)
- 新規: `src/dareba.js`、`public/widgets/dareba.html`
- 足す: `src/schema.js`、`src/runtime.js`、`src/admin.js`、`mcp/server.js`、`bin/tw.js`、`public/dashboard/simple.js`
- 新規テスト: `test/acceptance/dareba.test.js`、`test/dareba-wiring.test.js`

## 触らないファイル
- `config.yaml`、`data/`、既存の集計・履歴・Minecraft本体のルール、`src/hub.js`、既存テストの書き換え。
- 事件判定のために、画面へ勢いの数字や「冷えた」という文を出さない。

## 完成の条件
- AC-1 配信開始から600秒は自動事件を起こさない。以後、直前600秒の1分あたり平均を基準にし、直近180秒の合計が基準の3分合計の40%以下になったときだけ候補にする。基準が0のときは候補にしない。
- AC-2 候補になっても前の事件から1200秒未満なら起こさない。判定はサーバーの受信時刻で行い、画面の時計や再接続に任せない。
- AC-3 事件は `野良ボス`、`宝箱`、`号外` のいずれかを設定で選べる。自動事件は1回に1種類、進行中は次の事件を始めず、管理者の停止操作で中断できる。
- AC-4 入り0〜900msで端のざわつきと赤い光を2回まで、達成時は400msの無音後1500ms以内に結果を出す。1回の表示は3秒以内、点滅は1秒3回以下にする。
- AC-5 事件開始または達成に関係した送信者の名前とアイコンを、受信から300ms以内に出す。表示文は日本語だけにし、事件判定の基準値は見せない。
- AC-6 事件の色は小さい予告を青、進行を緑、達成を赤または金、特別な達成を虹とする。効果音はWebAudio合成だけで、BGMや外部音源を止める操作はしない。
- AC-7 `event` と `testEvent` を分け、配信中のテスト送信は基準・事件の待ち時間・集計に入れない。配信前のテスト状態はLIVE開始時に空にする。
- AC-8 `GET /api/dareba`、WebSocket、再接続で事件の種類・開始時刻・残り時間・停止状態を同じ形で復元できる。状態はサーバーが持つ。
- AC-9 公開JavaScriptはES5で、外部CDN・外部素材なし。右列と下を避け、送信者の表示を最初の0.2〜0.4秒に置く。

## 状態と失敗時
- `monitoring`、`triggered`、`active`、`stopped`、`completed` をサーバーで管理し、画面のタイマーだけで事件を進めない。
- 配信の開始時刻、前回事件の終了時刻、基準値が不足しているときは `monitoring` のままにする。
- RCONや既存演出の開始に失敗した事件は、事件名だけを画面に残さず、日本語の失敗状態へ戻す。
- 配信者が停止を押したら新しい達成報酬を出さず、進行中のタイマーと予約だけを片付ける。
- 同じ180秒の集計窓でギフトが増減しても、1つの候補から複数事件を起こさない。
- 再接続時に同じ `eventId` を受けた場合は、画面側で二重に開始しない。

## 演出の境目
- ダレ場の判定値は画面に出さず、事件の札だけを画面端から入れる。
- 事件開始から300ms以内に送った人の名前を出し、名前がない自動事件は「ライコネの事件」と表示する。
- 逃した場合は灰色の「逃げられた…」を400msだけ出し、失敗を責める文章にしない。
- 達成時は0.4秒の無音から文字を叩きつけ、色を赤または金へ上げる。
- 演出のどの段階でも画面全体を3秒以上隠さず、点滅を1秒3回以内にする。

## 作らないもの
