# redesign: ダッシュボードを「放送卓」の並びと黄色・紙の色に作り直す

考えた人: Claude(2026-10-25)。オーナーがデザイン案の中から選んだもの。見本は `docs/design/redesign/` にある(さわれる HTML と画像)。作る前に `~/ruu-work/skills/skills/kind-ui/SKILL.md` と `~/ruu-work/skills/skills/design-anti-slop/SKILL.md` を読む。

## オーナーが決めたこと

- 並び方は案1「放送卓」(`1.html`)。左に細いアイコンの列(ホーム・各ウィジェット・その他、いちばん下に使い方と設定)。上の帯に状態と「配信中に見る」「配信の記録」「ためしに動かす」。ウィジェットの画面は、見え方の大きな枠が上で主役、右にためすボタンと URL、設定は下に2列
- 色はダークが「黄色」(`1c.html?c=yellow`、画像 `1-yellow.png`)、ライトが「紙」(`1c.html?c=paper`、画像 `1-paper.png`)。設定の「画面の明るさ」でライト・ダークを切り替える(今の仕組みのまま)
- 案3「ドパガキ」(`3.html`)の、配信画面(9:16)の上に今のウィジェットを全部並べて見せる形も好き。見え方の大きな枠で「このウィジェットだけ / 配信画面ぜんぶ」を切り替えられるようにする
- スマホ(幅 768px まで)は案4(`4.html`)の形: 下にタブ(ホーム・ウィジェット・配信中・記録・その他)、使い方と設定は「その他」の中
- 目立ちかたは「シンプル|ふつう|ドパガキ」の1本につながったボタン(今のまま)。プレビューは 4:3(案1の大きな枠は横長でよい。中は比率を崩さない)

## 作るもの

1. 色を CSS の変数(トークン)1か所にまとめ、黄色(ダーク)と紙(ライト)の2組だけにする。今ある色の直書きは変数に置き換える
2. 案1の並び(左のアイコン列、上の帯、ウィジェットの画面の組み立て)にする。ホーム・その他のウィジェット・設定も同じ並びの中に入れる
3. 「配信中に見る」「配信の記録」の画面も同じ枠(左の列と上の帯)の中に入れ、ダッシュボードから出ないようにする(古い上のタブ「モニター・統計・設定」はなくす)
4. 見え方の枠に「このウィジェットだけ / 配信画面ぜんぶ」の切り替え。配信画面ぜんぶは、今の all.html を見本(preview=1)で映す
5. スマホは下のタブにする

## 完成の条件

- AC-1 PC 1280 で、左のアイコン列・上の帯・ウィジェットの画面の組み立てが案1と同じ(撮影して見本と並べる)
- AC-2 色が CSS 変数の2組(黄色・紙)だけで決まっている。`public/dashboard/style.css` に、変数の定義の外で色の直書きが増えていない
- AC-3 配信中に見る・配信の記録を開いても、左の列と上の帯が残る。配信者ごとの URL(/t/<鍵>/)の外に出ない
- AC-4 見え方の枠で「このウィジェットだけ / 配信画面ぜんぶ」を切り替えられる。見本は preview=1 で開く(配信ソフトからの接続として数えない)
- AC-5 スマホ 390 で下のタブが出て、全部のタブが押せる(幕がかぶらない)

- AC-7 公開ウィジェット・設定ファイルの形(schema のキー)・API は変えない
