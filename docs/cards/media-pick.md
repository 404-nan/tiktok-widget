# media-pick: 声と立ち絵の欄を、IDを打つ欄から「メディアから選ぶ」欄にする

for: 北極星
仕事の種類: 直す(小さく)
見た目が変わるか: 変わる(ダッシュボードの6つの欄が、文字の欄から選ぶ欄になる)

目的: カットインの声(青・緑・赤・金・虹の5つ)と、パチンコ演出の立ち絵(charImage)は、今はダッシュボードで「メディアのID」を手で打つ欄になっている。配信者は ID を知らないので、入れた音声や絵を使えない。ギフト別サウンドと同じく、入れたメディアの名前から選べるようにする。

前提(今のコード):
- `public/dashboard/editor.js` にはもう、メディアの一覧から選ぶ select を作る `fillSelect` と、メディアを足した・消したときに選ぶ欄を作り直す `refreshMediaSelects` がある(ギフト別サウンドで使っている)。これを使い回す。新しい部品は作らない
- 対象の欄は `src/schema.js` の `cutinFields` の `blueVoice`・`greenVoice`・`redVoice`・`goldVoice`・`rainbowVoice`(音声)と、`SCHEMA.puchuns.fields.charImage`(画像)
- 保存される値は今と同じ mediaId の文字。空は「なし」

## 作るもの
- schema のこの6つの欄に、メディアの種類の印(音声か画像か)を付ける。editor はその印のある欄を、その種類のメディアだけを並べた select(先頭は「なし」)で描く
- メディアを足す・消すと、この select も作り直される
- 前に選んでいたメディアが消えていたら、「見つからないメディア」と出し、選び直せる

## 完成の条件
- AC-1 実ブラウザでダッシュボードを開き、カットインの「赤の声」の欄が select で、入れてある音声の名前が並び、画像は並ばない。選んで保存すると config の redVoice がその mediaId になる
- AC-2 パチンコ演出の立ち絵の欄が select で、画像だけが並ぶ。選んで保存すると charImage がその mediaId になる。「なし」を選ぶと空になる
- AC-3 ダッシュボードでメディアを1つ足すと、開いたままの select にそれが出る
- AC-4 `npm test` が全部通る
