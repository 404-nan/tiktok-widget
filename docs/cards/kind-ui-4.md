# kind-ui-4: 準備の印を本当にする。配信が始まったら自動でつなぐ。消しても元に戻せる
仕事の種類: 作り込み(サーバーと画面)
見た目が変わるか: 変わる(本番に出す前にオーナーが開発サーバーで見る)

考えた人: Claude(2026-10-24)。skill `kind-ui` の決まり3(ライコネにできることは人にやらせない)・7(本当でない印は出さない)・8(元に戻せる)から。kind-ui-3 が終わってから作る。作る前に skill `kind-ui` を読む。

## なぜ

- 重さ4: 「配信ソフトに URL を入れた」の印は、今は出すものを選んだだけで付く(`public/dashboard/editor.js` の `obsList()`)。本当は入れていないのに済んだと思って配信すると、配信で何も出ない
- 重さ4: 「配信につなぐ」は毎回手で押す。ライコネが新しくなる(再起動する)とつながりが切れ、次の配信でまた押さないといけない。押し忘れると、配信中のギフトが何も出ない(妨害マイクラの枠だけは `src/tenants.js` の `#autoConnectRentals` で自動)
- 重さ2: プリセットを消すときがブラウザの確認(confirm)

## 作るもの

1. **準備の4つを、サーバーが確かめて覚える**(配信者ごとに、初めて済んだ時刻を残す)
   - ① 出すものを選んだ: 1つ以上オンにした
   - ② 配信ソフトに入れた: その配信者のウィジェットの画面が、配信ソフトから初めてつながったとき(hub の obs の client。ダッシュボードの中のプレビューは数えない)
   - ③ ためした: 「ためしに動かす」か「ためしにギフトを1つ出す」を押した
   - ④ 配信で使った: ウィジェットが入った状態で配信につながった
   - ホームの「配信の準備」をこの4行にする(GOV.UK の Task list の形)。行ごとに「済み / まだ」。まだの行には、それをするボタン
   - ② のボタンを押すと、URL のコピーと3つの手順を出す: 「1. LIVE Studio で［ソースを追加］を押す 2. ［リンク］を選ぶ 3. URL を貼って追加する」。LIVE Studio の日本語の画面の言葉は、オーナーに確かめてもらう(それまではこの言葉で書き、README の「まだ」に書く)。つながったら数秒で「つながりました」と出て、印が付く
   - 4つとも済んだら、一覧は1行にたたむ
   - 週の数字(`~/ruu-work/ops/bin/weekly-numbers`)に「準備のどこまで進んだ配信者が何人か」を足す(名前は出さない)
2. **配信が始まったら、自動でつなぐ**
   - TikTok の ID が入っていて、配信ソフトにライコネの画面が入っている(② が今つながっている)とき、配信が始まったら、ボタンを押さなくてもつながる
   - 配信していないときに Euler を使わない今の決まりは変えない(公開の様子で配信中かを確かめてから)
   - サイドバーの「配信につなぐ」は、状態の表示にする: 「配信を待っています(始まると自動でつながります)」「つないでいます…」「配信中・つながっています」。ID が入っていないときだけ、ID の入力と「つなぐ」を出す。つながらないときだけ「今すぐつなぐ」を出す
   - 設定に「配信が始まったら自動でつなぐ」(はじめは入。切れる)
   - 妨害マイクラの枠の自動接続は今のまま動く
3. **消しても元に戻せる**: プリセットを消したら、下に「消しました [元に戻す]」を10秒出す。confirm はなくす

## 完成の条件

- AC-1 ② の印は、配信ソフトからつながったときだけ付く(テスト: obs の client がつながる前は付かない / つながると付く / ダッシュボードのプレビューでは付かない)
- AC-2 自動でつなぐ(偽物の TikTok と時計でテストする): 配信していないとき Euler を呼ばない / ② がつながっていて配信が始まるとつながる / ② がつながっていないとつながらない / 設定を切るとつながらない
- AC-3 再起動のあとも、次の配信で自動でつながる
- AC-4 消してから10秒の間は「元に戻す」で戻る。confirm を使っていない
- AC-5 週の数字に、準備の段階ごとの人数が出る(`weekly-numbers --preview` で確かめる)
- AC-6 API の今ある項目の形は変えない(足すのはよい)。公開ウィジェットは変えない
- AC-7 `npm test` と `KIND_UI_PLAYWRIGHT=1` のテストが全部通る。README(一番上の機能の一覧、src と public/dashboard と ops/bin の README)を直す。lul-map に変わりがあれば直す
