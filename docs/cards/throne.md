# throne: 動く王冠と首位争いの乱入
仕事の種類: 作り込み
見た目が変わるか: 変わる

目的: 直近10分の合計が1位の人へ王冠を乗せ、王冠が移りそうな瞬間だけ2人のVS画面を出す。合計順位が固定されても、短い勝負を作る。

## 作るもの(触ってよいファイル)
- 新規: `src/throne.js`、`public/widgets/throne.html`
- 足す: `src/schema.js`、`src/runtime.js`、`src/admin.js`、`mcp/server.js`、`bin/tw.js`、`public/dashboard/simple.js`
- 新規テスト: `test/acceptance/throne.test.js`、`test/throne-wiring.test.js`

## 完成の条件
- AC-1 王座の集計窓は常に直近600000ms。境界時刻は含め、窓の外へ出たギフトは王座の合計から外す。合計が同じときは王冠を移さない。
- AC-2 新しい人の合計が現在の王を1単位以上上回ったときだけ王冠を移す。移動後は在位開始時刻をサーバー時刻で記録し、画面再接続後も継続する。
- AC-3 現在の王と2位の差が、現在の王の合計の15%以下になったギフトで `VS` を出す。王が0のときは差が1単位以下を接近とする。接近判定は同じ組み合わせで180秒に1回まで。
- AC-4 VSの入りは0〜600ms、山は600〜2000ms、抜けは2000〜2800ms。0.2〜0.4秒以内に両者のアイコンと名前を出し、900msにVSを表示して80ms止める。
- AC-5 首位交代ならVSの後に王冠を新しい王へ移し、「首位交代」ではなく「新しい王」と表示する。交代しなければ「防衛」とし、差の数値を出すかは設定で隠せる。
- AC-6 王冠の移動は1配信12回まで。上限後も順位と在位時間は更新するが、VSと移動演出は出さない。管理者の停止操作で演出だけ止められる。
- AC-7 1配信の終了時に、在位時間が最長の人を `名君`、最後の王を `最後の王` として1回だけ確定する。名前の表示は既存のNG判定を通す。
- AC-8 色は接近を青、VSを緑、首位交代を赤、王冠を金、最多在位の締めを虹とする。効果音はWebAudio、点滅は1秒3回以下、各演出は3秒以内。
- AC-9 `event` と `testEvent` を分離し、テスト送信は王座の集計・在位時間・終了称号を変えない。`reset` で王座と接近の待ち時間を空にする。
- AC-10 `GET /api/throne` とWebSocketで同じ状態を返し、画面はサーバー状態から再開する。公開JavaScriptはES5で外部素材・CDNを使わない。

## 状態と失敗時
- 王座は `idle`、`reigning`、`versus`、`finished` を持ち、順位計算と演出の再生を分ける。
- 直近600000msに有効なギフトがないときは王を作らず、空の王座を返す。
- 同じ時刻のギフトはサーバーが付けた受信順で並べ、画面の到着順を根拠にしない。
- 王座が移る前に設定を無効にした場合は演出を止め、順位データだけを保持する。
- VS中に新しい順位が来ても、同じ演出を重ねず、終了後の状態を1回同期する。
- 表示用の名前が空になったときは名前を出さず、アイコンと「新しい王」だけを出す。

## 演出の境目
- 王冠は画面の隅に常設し、王の名前と在位時間を1行で見せる。
- VSの2人は左右に置き、左を現在の王、右を挑戦者として固定する。
- 乱入のブザーは2回だけ鳴らし、VS直前に300msの無音を置く。
- 王冠の移動は弧を描く1回の動きにし、同じ人への往復アニメーションを重ねない。
- 敗者を指す文言は使わず、画面の文字は「VS」「防衛」「新しい王」「奪還」に限定する。

## 作らないもの
- 配信全体の合計順位を王座にする機能、差を煽る広告文、送った人を晒す文言、無制限の移動、大きな顔出しを常時続ける画面。
